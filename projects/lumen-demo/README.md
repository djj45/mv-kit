# lumen-demo — 样张：kits/lumen.js

不是 MV（没有歌：歌词是占位的原创句子，节拍是 120 BPM 的网格），是"发光数据 / 终端科幻"风格包的示范。六个镜头，每种调色板和主要技法各一个：

| 时间 | 镜头 | 调色板 | 演示 |
|---|---|---|---|
| 0–4 s | `boot` | ice | 线框二十面体逐边画出、顶点在拍点上闪；镜头自己的源码当暗纹理；引线标签钉在转动的顶点上；终端歌词 + HUD |
| 4–8 s | `galaxy` | ice | 14 万点旋臂星系（暖核冷臂），推近 + 景深；近处飘过的尘埃失焦成光斑；轨道圈画出 |
| 7.6–12 s | `arcs` | ember | 唱到一个字点亮一个节点，粒子尘弧线连回前面每个字，最新的一条是琥珀色；章节号 + 宽字距标签 |
| 12–16 s | `morph` | ember | 2.4 万点拼成的"名字"散成星系，再拼成"你"（`lmMorph`，不硬切）；数字滚动；底部字幕 |
| 16–20 s | `paper` | paper | 反相：米白纸上的技术图纸，洛伦茨吸引子（朱红点云 + 石墨轨迹线）在线框盒里画出，引线标注 |
| 19.75–24 s | `alert` | alert | 线框隧道冲向镜头，"SIGNAL LOST" 从乱码解出、在拍点上撕裂（整帧 `glitch`）；`glitch` 遮罩转场进入 |

```sh
open projects/lumen-demo/index.html
uv run tools/render.py projects/lumen-demo sheet --cuts
uv run tools/render.py projects/lumen-demo
```

用法见 `docs/ENGINE.md` 的 lumen.js 一节。

## 写 TREATMENT 时可以照抄的画风要点

- **规则**：画面上只有光。纯黑底，主体是发光的点和细线（0.6–1.6 px），叠加混合，密处烧白、边缘带色；泛光只给最亮处。没有面、没有阴影、没有贴图。
- **构图**：一个主体，大量留白；主体常偏右（`shift`），给左下的终端歌词让位。远近靠大小、亮度、景深光斑。
- **配色**：一镜一个调色板，按段落换：主歌 `ice`（冰白 + 青），叙事段 `ember`（香槟白 + 琥珀），情绪段 `rose`，高潮 / 崩溃 `alert`，冷静的解释段 `paper` 反相。强调色只给"现在"：正在唱的字、最新的连线、光标。
- **字**：等宽字做一切界面（终端歌词、HUD 读数、标签），细黑体只做居中字幕和大数字；字距放宽；文字离画面边缘 ≥ 96 px。
- **歌词**：二选一贯穿全片：左下终端（逐字打出、方块光标、旧行上移变暗）或底部居中字幕（逐字淡入）。也可以让歌词本身成为主体（节点、粒子拼字、拆字大标题）。
- **节奏**：两种剪法。快：每 1–2 小节硬切在小节头，冲击（顶点闪、`glitch`、大字跳动）落在拍点上。慢：几乎不切，靠 `lmMorph` 让一个图形散开、飞成下一个图形，镜头一直缓慢推移。
- **母题**：歌词里的名词变成数学 / 数据对象（"圆" → 圆、"心" → 心形线、数字 → 滚动计数）；一个程序化的"系统"在片中启动、运行、出错、重启。
- **禁止**：照搬参考片里的具体画面和字样；满屏霓虹；大面积糊成一片的泛光（泛光是点缀，不是底色）。
