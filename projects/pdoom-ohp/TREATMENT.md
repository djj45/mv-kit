# 《P(doom)》MV — 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> 项目：`projects/pdoom-ohp`（P(doom)，132 BPM，156.65 s，46 句歌词；歌曲与逐词时间沿用仓库里现成的 pdoom 素材）
> **这一版一次成片：方案、代码、qa 全部自己做完，中途不停。**

## 一句话概念

**这首歌是一场在暗教室里用投影仪（OHP）讲的课。** 观众看到的就是投在墙上的画面：一叠手绘的透明胶片、一支马克笔、一只伸进光柱里的手（影子）、灰尘、咖啡渍，和越堆越多的回形针影子。46 句歌词 = 46 张胶片。

讲课的人从头到尾没有露脸——**只有他在光柱里的影子**。他写、划、盖戳、翻页；歌越唱越急，胶片越翻越快，笔迹越写越乱，灯泡开始闪；到桥段（89 s）教室突然安静下来，只剩灯泡和一张不动的胶片；最后一段副歌整面墙烧成红色；结尾他伸手把灯关掉，墙上只剩余像和一枚回形针。

**为什么这样拍：** 这首歌本来就是一堆术语（AGI、Chinese room、shoggoth、basilisk、RLHF、CDR、P(doom)），最自然的容器就是"一张一张讲给你听的投影胶片"：每一句都能变成一张图解，图解本身可以很干、很冷，而"干冷"正好是这首歌的笑点。全片没有生成图片、没有视频素材，全部是 Canvas 2D 画出来的线条。

## 画风

- 参考方向（只写风格特征，不点名作品）：**1980 年代课堂投影胶片纪录片**——光柱里的灰尘、暖白的光斑、手绘胶片边缘的胶带与划痕、标记笔（marker）粗细略变的手写线、蜡笔（grease pencil）的红、打字机打出来的标签。不是"复古滤镜"，而是**画法本身就是这套工具**：一切线条都是笔画的，一切颜色都是笔的浓度。
- 线条：记号笔线宽 6–11 px（1080p），两端圆头，笔画内部有轻微粗细变化（沿笔画采样调的噪声），每张作画（`f.tick`，12 张/秒）整体抖 1.2–2 px —— 手绘的"呼吸"，不要机械直线。蜡笔（红）线更脏：双线叠画、略超出拐角、边缘带一点碎屑。
- 阴影 / 光：**光只有一盏**，从画面下方偏左打上来（投影仪在观众这一侧）。所以：①画面亮度以中下为最亮，四角偏暖灰；②伸进光柱的东西（手、笔、杯子、回形针）在墙上留下**影子**，影子向右上偏移、边缘半虚——手永远只以影子出现（不是画不出手，是这种片子本来就这样）；③胶片层叠的地方更暗一点点（多一张胶片 = 多一层吸收）。
- 质感：胶片（醋酸片）纹理：细划痕、指纹弧、尘点、胶带角；墙上有一层很浅的墙面颗粒；导出 `post.grain 0.055`、`vignette 0.38`（暗教室）。胶片上的墨是**吸光的**，不是发光的。
- 动态节奏：`drawRate: 12`（一拍二），手写的字、抖动的线、翻页的胶片都按作画张动；镜头运动（缓推 / insert / warp）用连续的 `f.t`。底鼓上画面轻微一震（`shake` 3–7 px，只在大段落），军鼓上灯泡闪一下（`flash 0.05–0.09`，暖白）。**没有静止的镜头**。
- 禁止项：
  - 不用"AI 味"的通用科幻：不要发光网格、不要霓虹渐变、不要粒子爆炸。光只有灯泡那一种。
  - 不做工业安全须知那一路（象形小人、警示三角牌、刻度盘）——那是这个仓库里另一支片子已经用过的语言。
  - 不出现具体 AI 产品界面截图、不出现真人肖像、不点名任何现实人物（"Ilya" 只作为歌词文字出现，配的画面是一只眼睛，不画脸）。
  - 不用大面积 `filter: blur`；不使用 `Math.random`。
  - 全片没有一处"照搬某部作品的具体画面"：所有图解都是这首歌自己长出来的。

一段一段的色温变化（这是全片的"调色"）：
- **A1–B1（0–23.9 s）**：只有暖白 + 黑笔 + 一点点蓝。干净、教学。
- **C1–F1（23.9–53.0 s）**：红蜡笔进入（P(doom) 第一次写），画面开始不平整。
- **B2–G2（53.0–89.3 s）**：红变多，蓝退场，划痕与叠影变多。
- **I1（89.3–109.3 s）**：冷。几乎只有灯泡的暖光和 `ink2` 的浅字，`vignette 0.55`，画面偏冷灰。
- **H2–J1（109.3–133.0 s）**：红警报。红蜡笔铺满，画面震，闪白。
- **G3–K1（133.0–156.7 s）**：红褪成锈色，最后回到灯泡熄灭前的暖光 → 黑。

## 字体

- 手写（歌词与批注）：`"Bradley Hand", "Chalkboard SE", "Comic Sans MS", cursive`
- 马克笔大写字（hook、大标题、FOOM）：`"Marker Felt", "Chalkduster", "Bradley Hand", cursive`（大词加 letterSpacing）
- 打字机（标签、清单、聊天窗、规格表）：`"American Typewriter", "Courier New", monospace`
- 数字/读数：`Menlo, "Courier New", monospace`
- 印章（SAFE / OBSOLETE / FLAGGED）：`"Avenir Next Condensed", "DIN Condensed", Impact, sans-serif`，加字距、轻微旋转、印泥不匀
- 中文（只在片尾卡出现两行）：`"PingFang SC", "Hiragino Sans GB", sans-serif`

**歌词规则**：逐词同步，每个词单独 `fillText`（未唱到的词一律不画或只画 `ink2` 的淡影，最多提前 0.4 s）；词在 `start` 那一刻**已经完整显示**（qa 就在那一刻量），不能淡入到看不见。所有歌词包在 `MV.lyric(() => …)` 里，字离画面边缘 ≥ 110 px。全片字号从 34 px（片尾小字）到 300 px（第三次 P(doom)），位置分布：下三分之一约 55%、画面中部约 25%、上部与暗底约 20%（避免 `type-band`）。

## 贯穿母题

1. **影子手 + 马克笔**：全片唯一"人物"。写字、划线、盖戳、翻页、最后关灯。它一出现，眼睛就看笔尖（`MV.focus`）。
2. **P(doom) 这个记号**：红蜡笔写在墙上，四次副歌一次比一次大（90 px → 150 px → 210 px → 300 px，最后一次几乎撑满画面），第四次写完笔尖把胶片划破。
3. **回形针**：第一段副歌光柱里 1 个影子回形针；第二段 2 个；桥段开始往下掉；"as paperclips fill the room" 时铺满下半屏；Hundred thousand GPU 之后每个机架上都别着一枚；片尾墙上剩最后一枚。
4. **那条曲线**：训练损失曲线（掉出画面）→ FOOM（竖直冲出上边缘）→ 奇点（卷成一点）→ sharp left turn（拐 90°）→ 导火索（同一条线在烧）。同一支笔画的同一条线，贯穿全片。
5. **光柱里的灰**：一直在飘；只在"sparks of AGI"和结尾灯灭时变亮/变暗。

## 技术约定

- 每一帧只由歌曲时间 t 决定（见 docs/ENGINE.md）：不用 `Math.random / Date.now`，粒子和点阵全部写成 t 的函数。
- 静态的东西（胶片纹理、墙面纹理、光斑、灰尘底图）在 `MV.onInit` 里画一次。
- 硬切落在小节第一拍或唱到的音节上；大动作落在 `f.a.kick / f.a.snare`。
- 每个镜头做完：`render.py sheet --cuts` 看拼板 + `render.py qa --from … --to …` 清零错误。
- 交付前整片 `qa` 没有错误；下面记录保留的警告与理由。

### 2. 两个"防打架"的工具（写进 `lib/ohp.js`）
- `OHP.inkOutside(g, f, pts, rect, o)`：一条笔画碰到矩形就停（Liang–Barsky 切分），虹膜的放射线用它避开歌词。

### 3. circuit → loss 的转场：选了"真的推进去"
原来两张画面差不多大，zoom 只是平移（lint 报 ×0.97）。现在 **loss 的坐标轴原点搬到电路那个红点的正下方 (820, 470)**，曲线就从红点开始长；loss 的锚点套在曲线起点上、面积是电路 140 px 锚点的 **2.7 倍**。`match: ['node', 'start']`——红点长大成整张胶片，这才是匹配剪辑。
（旧镜头不再把新镜头那句歌词画第二遍：`f.lyrics.lineAt(f.t, f.from)` 现在会去掉 `f.until` 之后才开始的句子；`strip --t 9.3` 里只有一份歌词，qa 无 `lyric-handover`。）

### 4. 两处绕规则的写法改回正路
- **focus 不再夹边**：foom / leftturn / show / transformers / clips 里 `Math.max(ty, 20)` 这类写法全删。主体一出画就**改报眼睛接下来看的东西**：曲线冲出上缘 → 报烧焦的边；路走出上缘 → 报拐角；手抽出画外 → 报空墙；方块堆冲出上缘 → 报最高的可见那一块。
- **loom 的织字**：一个字符一次 `fillText` 的写法删掉，整词画、包进 `MV.decor(() => …)`。它现在按普通的字查——**纬线穿过织进去的 "P(doom)" 就是这个画面本来的意思**（布上织出来的字当然有经纬线），`text-touch` 报出来就保留；两个小拷贝放大到 0.72 / 0.56 倍，看得清。

### 5. 画面质感
1. **影子手**：重画。手指一根根分开（食指压在笔杆上、拇指从下面绕过来、三根手指蜷着），手掌比手腕宽，前臂再宽一圈、**一定伸出画面**（不再有圆头断截）；半影三层（1.022 / 1.05 / 1.085 倍，透明度递减），笔在贴墙那头最黑。手比第一轮大（s 0.55–1.0，按镜头）。
2. **回形针**：线宽 0.30 → **0.07**，一根连续的铁丝（两个圈 + 内端收在中间），影子版是三层软边、透明度 0.35–0.5；clips 里堆成两堆时每一枚还认得出来。
3. **胶片本身**：`OHP.back` 现在**每一镜**都画胶片——内缩与角度按镜头号 `hash`（40–74 px、±0.46°）、受光边 + 内侧细线、片下阴影、两角胶带；讲课段（0–106 s）每次换镜头用 `swap`：新胶片放下时那一下影子从画面上方退出。

### 6. 这一轮保留的警告（就一条）
- `text-touch 16.07 boss："THE MODEL" has drawing running into it (5.4 em)` —— **故意**：`THE MODEL` 上那道红线就是要划掉它（"上面那个框，在你填进去之前就已经划掉了"）。这是这一镜的意思，不是失误。

- 第一轮提的几条这一轮都落地了：`MV.decor`（织进布里的字不算歌词）、`lineAt(t, from, until)`（旧镜头不画新镜头那句）、`lyric-touch` 报**不同颜色**的线穿过字、`zoom` 的 lint（两个锚点一样大就报）、`MV.focus` 的"故意出画"写法。正好对症，谢谢。

## 给框架的反馈（如果要把这套画风做成 kit）

- **marker / 投影胶片这一路可以独立成 `kits/ohp.js`**：记号笔笔画（沿弧长的宽度呼吸 + 按 `f.tick` 抖动）、
  蜡笔双 pass、影子手、回形针 / 猫等剪影、印章、打字机标签、“擦掉一块墨”的留白、烧线（`burn`）。
  这一版全部写在 `projects/pdoom-ohp/lib/ohp.js`（约 700 行），换一首歌可以直接搬。
- **`MV.focus` 需要一个“故意出画”的开关**：qa 的 `focus-out` 是错误级，但有些主体本来就该走出画面
  （掉出画面的回形针、冲出上缘的曲线、伸出画外的手）。我现在的办法是把报送的坐标夹回画面内（5 处），
  语义上不对。建议 `MV.focus(x, y, name, { exit: true })`，或让 `CAM.keep` 与它联动。
- **一个词单独放大**（hook 的做法：三个小词 + 一个 300 px 的大词，同一基线）在 MV 里很常见，
  `karaoke()` / `BOX` 都没有这个用法；我写了 `OHP.lyricBig`。可以进 `kits/layout.js`。
- **qa 的 `isLyric` 按文字内容匹配**：图解里写一个 “AGI”、织布上写一个 “P(doom)”，就会被当成歌词，
  报 `lyric-carryover / lyric-overlap`。我最后靠“一个字符一次 `fillText`”绕过去（单字符不算词）。
  建议给一个 `MV.decor(() => …)` 之类的反向标记。
- **`static` 按整帧像素变化率量**：线稿镜头（一条细曲线从画面里长出去）即使一直在动也容易判“几乎没变”。
  建议把“笔画像素”的变化单独量一档。
- **`type-flat` 用 5–95 百分位**，所以少数几个特大字（hook 的 330 px）不进统计，得靠整体分布拉开；
  按 min/max 量会更符合“全片字号要有大有小”的本意。
