# 《青花瓷》MV — 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> **区间**：第 8–42 小节（0:18.15 – 1:33.71，34 小节 = 75.6 s）。108 BPM，4/4，一拍 0.556 s，一小节 2.222 s。
> **主歌**（第 10–25 小节）＝ L1–L13「素胚勾勒… … 去到我去…」；**副歌**（第 25–41 小节）＝ L14–L25「天青色等… … 你眼带…」。
> 段落能量：主歌 0.23–0.27（很轻），副歌 0.97–1.00（全乐队）。**这个落差就是全片的明暗落差**——主歌只有一盏灯，副歌幕布整面亮起来。
> 全曲几乎每句都在小节第 3 拍（或第 2 拍末）弱起，所以切点大多落在第 3 拍或前一个小节头。

## 一句话概念

**一盏油灯、一张白幕、一个影人。**

他是村里最后一个影戏艺人。**主歌在幕后**：他刻皮、上色、装签，一刀一刀把"她"刻成一个影人。**副歌切到幕前**：雨落在幕布上，影人活了，江水从幕布上横过，而一个女人的剪影出现在幕布前面——隔着那层布，谁也没走到谁那边。

歌里"画在器物上的她"，在这支 MV 里全部换成"刻在皮上的她"：

- 歌里的**"青花"**＝影人衣服上那一抹透光的**靛青**（全片唯一的彩色）；
- 歌里的**"瓶底书…"**＝在影人**竹签的底部**刻字；
- **全片不出现任何瓷器、窑、瓶**（已确认，见文末。理由四条）：
  1. 歌里的"青花瓷"是**比喻**，不是画风。把它当画风，画面就只是复述歌词（唱"釉色渲染…"就给一个分水特写），MV 变成插图；换一种工艺能保住同一套结构（手艺人做"她"的像），同时让画面去**评论**歌词。
  2. 两种工艺的物理对应两种情绪：瓷器烧成就定了、不变、可以传世——**物**的时间；影戏一盏灯一块布、灯灭戏散、影人只在有人握签时才活着——**人**的时间。这首歌的第一人称是那个够不到的人（等烟雨、隔江千…、去到我去…），而"如传世的…"恰恰在说**瓷器不需要他**；整片若是瓷器，这句就没有落差。
  3. 瓷器最贵的地方正是程序化绘制最容易露怯的地方：分水积边、铁锈斑、晕散、釉面高光、缠枝纹的精确度（少一分就像脏滤镜）。影戏靠形和光，手作感用"刀口的抖"表达，不靠堆细节量。
  4. 明暗落差：一盏灯天然有"黑屋 → 整面幕布亮起"这个开关，正对主歌 0.25 → 副歌 0.98 的能量跳变；瓷器是蓝白高调、层次细微，11 个镜头保持一致要难得多。
- **全片不出现一张真实的脸**：所有人物都是影子（艺人只有剪影和手，影人只有三刀）。

## 故事（四幕）

1. **点灯（前奏，第 8–9 小节）**：黑。灯芯被点着，幕布从暗里浮出来。桌上一张没刻完的皮、一把刀。
2. **刻与上色（主歌，第 10–25 小节）**：走刀、镂空牡丹、点朱砂、灯烟穿过窗格、画稿上的脸只刻了一半就搁下刀。他给影人染上靛青，补上嘴角那一刀——影人的手指第一次自己张开（含苞待放）。
3. **一缕飘散（主歌末，第 24–25 小节）**：靛青从指间飘散成烟，飘向幕布。镜头跟着它**穿过幕布**——第一次从正面看这块布，一个空白的亮面。
4. **幕前（副歌，第 25–41 小节）**：雨落下来，幕布湿了、暗了（"天青色"就是被雨打湿的幕布的颜色）；江与炊烟在幕布深处升起，一条江水横过画面（"隔江千…"）；他在竹签底部刻字（"伏笔"）；第二遍副歌雨更大，他在铜盆里把月亮**捞**起来，月亮碎成一片白、顺着幕布晕开；白光退去，只剩影人一个人站在幕上——**最后一刀，眼睛弯了起来**。灯捻小，灭；黑一小节，右下角落一方朱砂小印。

## 画风

- **参考方向（风格特征）**：背光影戏——单一光源（油灯）、半透明皮影、幕布透光。不是水墨（没有毛笔的浓淡飞白），不是瓷器（没有釉面和纹样框）；是**剪影 + 光**：形靠剪影，明暗靠"离灯、离幕的距离"，纹理全部来自"刻掉的部分透出来的光"。
- **线条**：**刻刀线**——影人身上的纹样是"镂空的亮缝"，不是描出来的线。缝宽 3–6 px（1080p），边缘留 0.5–1.5 px 的手抖不齐，**随 `f.tq` 每张作画变一次**（line boil，像真的一刀一刀刻的）；拐角是"方角 + 小圆角"（刻刀转弯的特征）。剪影的外轮廓**不描边**，只靠形。
- **阴影 / 光**：全片只有一个光源（油灯），没有"打光"，只有距离。
  - 影分**两层**：① **实层**（贴在幕布上的部分）边缘 1–2 px 锐；② **虚层**（离幕 1 层）按离幕距离 `d` 放大 1.05–1.35×、模糊 4–26 px、浓度 0.35–0.7。
  - 灯焰亮度跟着段落能量走：主歌 0.55 → 副歌 0.95 → 最后一镜 0.2 → 灭。
  - 影子大小/虚实是这支 MV 的**表演手段**（也是母题 3）。
- **质感**：幕布（经纬细纹 1 px、褶皱的亮度带、被雨打湿后透光降 15–35%、水痕边缘略深）；皮（透光处的丝纹、厚薄不匀）；灯烟（噪声场，不是粒子模拟）；灯焰（每帧 ±3% 呼吸 + 一拍二的形变）。
- **动态节奏**：`drawRate: 12`（一拍二）驱动影人的关节、手、刀的走线；**灯焰、烟、雨、江水用连续的 `f.t`**；雨打在幕布上的扩散写成"落下后经过的时间"的函数。
- **镜头语言**：
  - **幕后机位（主歌）**：逆光近景。幕布是背景（亮），前景是压暗的手 / 刀 / 皮 / 灯（剪影）。缓推为主，`f.a.kick` 时给 1–2 px 轻微震动。
  - **幕前机位（副歌）**：正对幕布的平面构图（像坐在台下第一排）。只有缓推、缓拉、极缓慢横移；第二遍副歌用同一个构图，只把雨、水、光加大。
  - **全片只有 3 次硬切**（进副歌 / 进"刻字" / 进"自顾自…"），其余 8 个镜头都用"光的变化"接（灯亮起来、幕布被雨浸湿、白光穿幕）——影戏的转场就是灯和幕。
  - 幕布**始终铺满画面**（幕布＝画布），只有最后一镜最后 2 秒拉远，露出幕布的上沿和挂绳。
- **禁止项**：瓷器、窑、瓶、开光 / 缠枝纹样；红灯笼、祥云、金龙、竹林等"中国风"套路；影人的脸超过三刀、任何写实人脸；粒子星云、霓虹、bloom 发光、镜头光晕；大面积 `filter: blur()` 假装晕染；**不用 pigment.js**（它是"颜料吸进纸里"的合成器，和"光穿过皮子"的物理正好相反）；画面里不出现任何 UI / 标签文字。

## 字体

- **歌词**：宋体族 `"Songti SC","STSong","Noto Serif CJK SC",serif`——横细竖粗，像刻版和戏单。字高 68 px（1080p），字距 +6 px。
- **款识 / 印章**：楷体 `"Kaiti SC","STKaiti",serif`，只在最后一帧出现"青花瓷"三字和一方朱砂小印。
- **歌词规则**：字在唱到时，从"未刻"（幕布上一点暗痕，alpha ≤ 0.18）在 0.18 s 内**刻穿**成透光的亮字，绝不抢跑；可提前 ≤0.3 s 以极暗的痕预示。字固定在**幕布上 1/4 的留白带**（横排居中，基线 y ≈ 0.20H），离画面边缘 ≥ 96 px；影人的动作高度够不到这条带，雨 / 烟 / 江水经过这一带时淡 60% 让开。

## 人物与道具（原创）

- **他（艺人）**：只以剪影和手出现（逆光），没有正脸。瘦、长衫、袖口挽起。**手是这支 MV 里最重要的表演器官**。
- **影人（她）**：牛皮刻成，三刀脸（眉、眼、唇）；衣纹是镂空的折枝牡丹；衣服染靛青。关节：肩、肘、腕、胯、膝、踝，加一根脖签、两根手签。身高 420 px（约幕布高的 40%）。
- **道具**：油灯（唯一光源，灯芯可捻大捻小）、刻刀（刀尖一点亮）、竹签（操纵杆，底部刻字）、铜盆（接雨，水里能看见月亮）、窗格（把灯光切成格子投在幕布上）。

## 贯穿母题

1. **一根线**：刻刀走的线 → 影人的轮廓 → 幕布上的雨线 → 横过画面的江水。它从桌面出发，最后横过整个幕布。
2. **一抹靛青**：全片唯一的彩色。第一次出现在"青花"两个字上（刀线里渗出靛青），最后一次在影人的衣服上被雨冲淡。
3. **离幕的距离 ＝ 影子的虚实**：贴幕时锐利，离幕时虚而大。结尾他退到幕后，他的影子变大变虚，她的影人小而实——两个人隔着一层布。
4. **灯焰**：开场点亮 → 副歌亮到最满 → 最后一镜捻小、灭掉。灯灭后黑一小节，落一方朱砂小印。

## 技术约定

- 每一帧只由歌曲时间 `t` 决定（见 `docs/ENGINE.md`）：影人关节、手、刀线用 `f.tq / f.tick`（一拍二）；灯焰、烟、雨、江水用连续的 `f.t`；雨落在幕布上的扩散写成"落下后经过的时间"的函数，不做粒子累积。
- 切点全部由 `timeline.js` 的 `cut / after / start` 从歌词算出（本曲几乎每句都在第 3 拍弱起，切点大多落在第 3 拍或前一小节头）。主歌每镜 2 小节，副歌每镜 4 小节。
- 新风格包 **`kits/shadow.js`**（与歌无关、可复用）：
  - `lamp(g, x, y, t, o)`——油灯、焰的呼吸、光锥；
  - `shadowOf(g, draw, { depth, blur, scale })`——按"离幕距离"渲染剪影（放大 + 模糊 + 浓度），全片影子虚实的唯一来源；
  - `screenCloth(g, { wet, offset })`——幕布经纬、褶皱、湿痕（按世界坐标钉住，镜头平移时布纹不游）；
  - `cutPattern(g, shape, { width, jitter, tick })`——刻刀镂空出来的亮缝（刀口不齐、方角拐角）；
  - `screenRain(g, t, { amount })`——打在幕布上的雨：深色圆点 + 水痕 + 透光衰减；
  - `carvedLyrics(g, f, { y, size })`——歌词：未刻 → 刻穿的逐字动画；

## 施工笔记（写后面 8 个镜头时别再踩）

1. **每样东西先想清楚它在哪一层**（离幕距离 `z`）。皮 `z≈55`、手 `z≈110–220`、他退到幕后 `z≈330`；不同层的投影系数不同，**同一个"设计坐标"在两层的屏幕上会差几百像素**。跨层对齐一律用场景里的 `toLayer(p, z)` 反投影，否则刀尖永远咬不住刀缝（这三镜最大的一个坑）。
2. **刀线要是一条连续路径**：`peony()` 现在返回一条不断笔的 `path`（茎上去 → 顺路勾叶子 → 花心 → 五瓣 → 花苞），`parts` 只给"只刻一半"的镜头用；分段折线会让刀在段与段之间瞬移。
3. **`upto` 一律按长度算**（`polylineUpTo` 与 `cutStroke` / `dyeInto` 已统一）。按点数算前缀会让刀和刀缝错开一大截。
4. **指缝要留出来**：手指间距要大于指宽（12 px 指 / 15.5 px 间距），并在 `o.edge` 里给手指画受光边；否则手影糊成一团。
5. **深色压在深色上会消失**：刀是深色的，皮要够透（半透明琥珀）才压得住；刀口的亮边要一直画到刀尖。
6. `check` 每个镜头只渲一帧，**抓不到"首帧才崩"的错**。关键镜头出片前用 `stills --t <镜头起点>` 或 `strip` 补验（镜头 2 首帧就崩过一次）。
7. **幕布不要跟着镜头推近**（镜头 9 推近后幕布出了画面、整帧全黑）：`screenCloth` 与雨留在屏幕空间，只把要放大的物件套进 `CAM()`。
8. **笔和刀的朝向不一样**：刻刀的柄在 −x（和刀尖同轴），毛笔的杆也在 −x——手要放在 `translate(-110, 8)` 这一侧，放 +x 就只看得见拳头。
9. **靛青是吸光的**：染过的皮应该更暗更闷（`rgba(20,50,84,·)`），用亮蓝就会变成"穿了一条蓝裙子"。
10. **`puppetPose` 只返回它自己列出的字段**：新加的姿势参数（`open / mouth / smile / walk / turn / handle / rodA`）必须在返回对象里显式带出去，否则场景传了也没用（握把就是这么丢的）。
