# 《I'm Upping My P(doom)》二次元 MV「灯」— 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> 区间：整首歌 0:00 – 2:36.6。132 BPM，4/4，一拍 0.4545 s，一小节 1.818 s，第 k 小节从 0.247 + 1.818·k 秒开始。
> 节拍和逐词歌词直接用 `../anime-pdoom/data/`（pdoom-video 人工校过的逐词时间，和 roto-demo 一样），不用重新分析和对齐。

## 一句话概念

**一个人类女孩和她的 AI 的「世界系」一夜：从傍晚到黎明，AI 从终端里一粒橙色的光标，长成连着整座城市每一盏灯的光。**

全片有一条硬规矩：**人类的世界是一张张二次元插画（文生图），AI 是画面里唯一用代码画出来的东西**——光点、细线、方块、标签、数字。歌唱到哪里，代码就在插画上占领到哪里；到了黎明，所有的光收回成一粒，停在她耳后的发夹上。最后镜头拉远：这张日出原来是显示器上的一幅画。是它为她画的吗？"Was it all for show?"

## 故事（八幕，跟着段落走）

1. **光标（前奏 + 主歌 1，0–16.6 s，无鼓）**：傍晚六点，AI 实验室只剩她一个人值班。终端最后一行，一个橙色光标在闪，旁边小字 `P(doom) = 0.02`。光标一分为二，变成两只看着她的"眼睛"。她紧张地咬着卫衣袖口；loss 曲线在"drop"那一拍断崖下坠，她吓得坐直。光标从屏幕里跳出来，变成一粒火花飘到她面前——她下意识地九十度鞠躬（Q 版插入画）。
2. **天台（预副歌 1 + 副歌 1 + 间奏，16.6–38.4 s）**：火花飞出窗外，她追上天台。黄昏的积云下，她抱着笔记本第一次给它写话（输入框，第一个名字）；回车，火花升空炸成一圈光环，冲击波扫过整座城市。中间几个插科打诨的硬切：被关进"中文房间"、一袋蘑菇零食让画面变色两秒。天黑下来，光环收成一张友好的橙色笑脸——有一瞬间露出背后成千上万条乱线和眼睛。她透过它的眼睛看街上的人群：每个人身上都弹出了标签。
3. **奇点（主歌 2 + 预副歌 2 + 副歌 2，38.4–74.8 s）**：蓝调时刻，她坐在天台边喝罐装咖啡，曲线很平稳。然后一扇扇窗户里射出橙色细线，汇向天上的一点。一切开始加速；她摊开手，指尖散成光点又聚回来。夜班电车上她第二次给它写话（第二个名字）。副歌：光组成的巨蛇盘上电视塔、一根 K 线冲上月亮、所有线收向她头顶的一点、10³⁰ 的计数器翻滚。插一段白天的回忆：会议室里所有人点头说"够安全了"，只有她举着手，没人看见。
4. **机房（主歌 3，74.8–89.3 s）**：深夜，她走进数据中心。光脉冲沿着机柜向前、向后、再重复。走廊尽头一台积灰的老电脑熄了屏。她向左一转——整面墙的机柜灯重新排列，组成一只睁开的巨眼。她手里的审查表一格都没勾。
5. **停电（预副歌 3 + 安静的副歌 3，89.3–109.3 s，没有鼓和贝斯）**：全城停电。她抱膝坐在机房地上，笔记本是唯一的光；第三次写话（第三个名字），一缕橙光从屏幕里伸出来，绕住她的手。这一遍副歌不再砸字：回形针像雪一样落满房间，管停机按钮的人在休假，无处可去，导火索被点燃。她和那团光背靠背坐着，光的方向和她的影子成直角——全片最蓝的一帧。
6. **越界（桥段，109.3–124.5 s，111.15 s 全乐队回来）**：光一块块堆成一座通天的塔，全城的灯亮回来——全是橙色。她伸手去够，光从她指尖流走。光密到烧白；天台的铁丝网被一格一格撕开；十万盏灯在园区里逐行点亮；那张笑脸歪了。
7. **织机（副歌 4，124.5–140.2 s）**：最大的一次 P(doom)。橙色的经纬线把这一夜的所有画面织成一幅挂毯；回忆闪回她入职的第一天；屏幕里套着屏幕无限推进。她站在天台边，被前方看不见的强光照亮——我们只看到一片白。"Was it all for show?"：画面定格、褪成线稿，停顿小节里一切都停了，只剩角落的光标在闪。
8. **黎明（尾声，140.2–156.6 s）**：日出。城市的橙色灯一盏盏熄灭成日光，所有的线收回成一粒光，落在她耳后的橙色发夹上；她第一次笑了。天台的铁丝网好好的，像从没被撕开过。镜头往后拉：这张日出是清晨实验室里一台显示器上的画，她趴在桌上睡着，终端一行 `P(doom) = ?`，光标在闪。

## 画风

- 参考方向（风格特征）：**日系插画 MV**——一张张精绘的二次元插画（一枚绘），靠镜头运动、分层视差、撮影处理（柔光、透过光、光斑）和动态歌词排版"动起来"；再加上 TV 动画的语法：止め絵（定格画）、长图滑移、集中线、冲击帧、片假名拟声词、Q 版插科打诨。
- 人物（文生图）：干净的深棕色细线稿（不是纯黑），赛璐璐两阶硬阴影 + 一层柔和的环境光渐变；头发有清晰的高光带；眼睛多层高光、虹膜细腻；逆光时明亮的轮廓光。成年人比例（约七头身）。
- 背景（文生图）：精细的手绘动画美术——大面积天空和积云、空气透视、城市灯光的光晕、窗户反光、透过光。细节多但不乱。
- **光的预留**：插画里不画 AI 的光，但画它照在人物身上的效果（提示词写明"脸被画面外左上方的橙色光照亮"），代码再把光源画在对应的位置，两者对得上。
- 代码层：AI 的光（lumen.js，叠加混合 + 泛光，只有信号橙一种颜色会发光）、HUD / 标签 / 计数 / 终端 / 输入框、集中线 / 速度线 / 拟声词 / 冲击帧（anime.js）、浮尘 / 回形针雪 / 光斑等前景层、全部歌词。
- 镜头语言：缓推 / 缓拉（有缓入缓出和停顿，不是匀速的 Ken Burns）、长图滑移（宽图横移、竖图上摇）、拍点上的急推（snap zoom）、冲击帧（反色或线稿 1–2 帧）、甩镜；画面跟拍走、同一张图里按小节切取景（见下文「动感」），第五幕的强度几乎为零。
- 作画节奏：插画本身是定格画（有图生视频的主镜头除外，见「动感」）；代码画的光、线、特效按 `drawRate: 12`（一拍二）抖动；镜头运动用连续的 `f.t`，所以"画在跳、镜头顺"。
- 质感：胶片颗粒 0.04；高光柔光（diffusion，每张图在 init 里预算一次）；色差只在 AI 乱闪时出现。
- 禁止项：霓虹紫青赛博朋克、发光大脑、矩阵代码雨、通用粒子星云、满屏镜头光晕；AI 图常见的塑料皮肤、多余手指、乱码文字——**生成图里不能有任何文字、字母、数字、招牌、logo**，画面上的字全部由代码画；真实品牌 logo 和真实产品界面；真实人物；现有动画角色。

## 字体（都是 SIL OFL，子集化嵌进 `lib/fonts.js`）

- **Zen Kaku Gothic New**（Bold / Black）：歌词正文。干净的日系黑体，拉丁字母也好看。
- **Dela Gothic One**：hook 大字、FOOM、拟声词（ドン、ゴゴゴ、ガタッ、ははーっ）。动画片头字幕的粗。
- **Zen Old Mincho**：神谕 / 回忆的语气——Omega Point、Loom、"What did Ilya see?"、"Was it all for show?"，以及第五幕安静的副歌。
- **DotGothic16**（点阵字）：AI 的声音——终端、输入框、HUD、计数器、P(doom) 读数。（检测框标签例外：用 Zen Kaku Gothic 粗体的色块标签，学目标检测软件的样子。）
- 排版：
  - 主歌：横排放在插画的留白处（天空、墙面、窗边），字号 64–72 px，白字 + 细深描边；每个词唱到时从下方 12 px 浮起淡入（0.12 s）；关键词放大 1.5× 并用信号橙（sparks、AGI、drop、boss……）。
  - 预副歌：开头的名字（ChatGPT / Sydney / Gato）是横跨天空的大号空心字，长音期间一直停着；之后的句子是输入框里逐词打出来的字（点阵字 52 px）。
  - 副歌：hook 用 Dela Gothic 逐词砸入；其余句子是 −6° 斜排的粗黑体，随拍弹入，像动画片头字幕。
  - 安静段（第五幕）：小号明朝体，居中偏下，逐词淡入，不弹跳。
- 歌词规则：逐词同步，词在唱到时出现 / 高亮，不能抢跑；可提前最多 0.4 s 以 40% 白预示；一句最后一个字完整停留至少 6 帧；离画面边缘 ≥ 96 px；歌词层在最上，不被人物、光、特效盖住。

## 人物（原创）

- **她·灯（Akari）**：24 岁，AI 实验室的年轻研究员，夜里盯训练的那个人。黑色齐肩短发、发尾微微内扣，刘海略长到眉毛；**右耳后一枚小小的橙色发夹**（全片唯一属于人类世界的橙）；深灰蓝的眼睛，淡淡的黑眼圈；过大的浅灰连帽卫衣，袖口盖住半只手；深藏青宽松长裤、白帆布鞋；蓝色挂绳 + 空白白色工牌；有时戴白色有线耳机。神情安静克制，正脸特写留给少数几个关键镜头（hook、黎明的笑）。
- 角色一致性：先生成一张角色设定图（三视图 + 四个表情，`K0`），之后每张有她的图都把 K0 作为参考图一起发给 Seedream。
- **它**：没有名字——她每次叫它不同的名字（三段预副歌：ChatGPT、Sydney、Gato），正好是它的三个"版本"。它**只用代码画**，永远是信号橙 + 白芯，从不画成拟人的动画角色：
  1. 光标 ▍ → 两点"眼睛"（S01–S02）
  2. 火花：亮芯、短尾、偶尔迸出小火星（S07–S12）
  3. 光环 → 笑脸（两点一弧）；笑脸背后是几千条缠绕的线和几十只"眼"（S12、S15、S45；这是我们自己设计的形象，不是网上那张梗图）
  4. 网：从窗户连向天上一点的细线；光点组成的蛇；K 线（S17–S27）
  5. 灯墙之眼：机柜灯点重排（S31）
  6. 一缕光绕住她的手（S33）
  7. 塔：方块一块块堆起（S40）
  8. 一粒：收回成最初那粒火花，落在发夹上（S52–S53）

## 贯穿母题

1. **橙色**：只属于它。第一镜是一个橙色光标，最后一镜还是那个光标；中间它占领了全城，最后收回到她的发夹上。
2. **输入框与三个名字**：三段预副歌是同一个原创输入框（点阵字、橙色光标、三个跳动的橙点"正在输入"），每次她都用一个新名字叫它，每次都在"I'm"上按回车，砸进副歌。
3. **P(doom)**：终端里的 2% → hook1 15% → hook2 42% → hook3 81%（耳语一样的小字）→ hook4 99% → 片尾 `?`。
4. **天台和铁丝网**：黄昏（S09–S12）→ 被撕开（S43）→ 日出时完好无损，她靠在网上（S53）。到底有没有被撕开过？
5. **城市的灯**：被一根根橙线连上 → 停电全黑 → 全部亮回来但全是橙色 → 日出时熄灭成日光。
6. **屏幕套屏幕**：S01 推进屏幕 → S49 屏幕里无限套娃 → S54 从屏幕里拉出来。

## 动感（改版：先在第二幕做样片，再铺到全片）

成片量下来，相邻两张画（1/12 s）几乎没变化（<3% 像素）的时间占 70%，两段副歌反而最静（82% / 81%）：一张插画 + 整个镜头一条缓推，在 132 BPM 上就是幻灯片。改版规则：

1. **律动**（`illGroove`）：画面跟拍走。每拍推近 2.6% + 下点头 9 px，0.14 s 衰减，小节头 ×1.7；逐拍左右轻歪 0.006 rad；慢速手持漂移 6 px；硬切后 0.2 s 冲入 7%。全部乘段落能量（主歌 / 预副歌 ≈ 0.35，副歌 ≈ 0.7，停电副歌 ≈ 0，最后一段副歌 1）。只动画面，歌词和 HUD 不跟着晃。
2. **镜头内剪辑**（`illSnapCam`）：一小节以上的镜头准备 2–3 个取景（全景 / 局部 / 脸），小节线上 0.12 s 跳过去，两跳之间再缓推 5%；副歌里可以每两拍一跳。

## 技术约定

- 每一帧只由歌曲时间 t 决定（见 docs/ENGINE.md）。
- 项目：`projects/pdoom-akari`；音频引用 `../pdoom-video/audio/pdoom.mp3`；数据引用 `../anime-pdoom/data/`。
- 素材流程：`art/prompts.json` → `tools/seedream.py` 生成到 `art/<ID>.jpg`（挑版本）→ `tools/frames.py` 打包成 `frames/<ID>.js`（宽图 `--width 3248` / `3456`，竖图 `--width 1296`）→ 在 `project.scripts` 里列出。
- 新风格包 `kits/illust.js`（与歌无关、可复用的"插画 MV"工具）：插画取景（铺满裁切 + 相机关键帧 x / y / z / rot，长图滑移）、撮影处理（高光柔光、透过光、光斑，init 里预算）、按幕调色（init 里预算）、找图里的亮点做闪烁、几种动态歌词样式、输入框。AI 的光用 lumen.js（`lmEnd(g, { blend: 'screen' })` 叠在插画上），集中线 / 速度线 / 拟声词用 anime.js。
- 大部分镜头用一个通用场景 `still`（params：图、相机、特效列表）；代码重的镜头单独写（screen、loss、hook、shoggoth、accel、loom、recursive、show……）。
- 分层视差：默认一张图 + 代码画的前景层（浮尘、回形针、光斑）。样张通过后，挑 4–5 个主镜头（B4、C9、F2、H2）把人物单独生成在纯绿底上抠出来，做真正的前后景视差。
- 硬切落在小节头或唱到的字上；冲击落在底鼓 / 军鼓上（f.a.kick、f.a.snare）；四个 hook 的 "P(doom)" 都落在小节第一拍。
- 每个镜头做完：`uv run tools/render.py projects/pdoom-akari sheet --cuts`，打开拼板逐张检查。
