# AGI · BOLT — 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> 拆解参考：`docs/REFERENCE-pdoom-video.md`（它总结出的 A–L 十二条，本片逐条落地，见文末「借了什么」）。

## 一句话概念

**全片是一台通用智能机的工程图。**

先画在纸上：DeepSeek 蓝的墨线，尺寸线，剖面线，公差，零件号。第 23 秒，纸上的墨被高压击穿——墨点离开纸面，飞进纯黑里成为电、成为光、成为雷。之后七分钟它在黑暗里运行、加速、越界、失控；最后落回纸面，只剩一根还在放电的线。

**两个语域，一套色**（参考片 §0 的教训：统一「色」，变化用「体裁」）：

| 语域 | 名字 | 底 | 画法 | 用在哪 |
|---|---|---|---|---|
| 图纸 | **PLATE** | 纸 `#E9EDF7` | 墨线、剖视、尺寸、网点、等宽小字；纯 Canvas 2D | 主歌、安静段、尾声 |
| 雷 | **VOID** | 黑 `#04060E` | 点云、细线、电弧、白热核心、泛光；WebGL（kits/lumen.js） | 副歌、引爆、失控段 |

同一台机器在两个语域里是**同一份几何**：`lib/parts.js` 里一个零件只定义一次（三角网格），PLATE 用 `solid.js` 投影成实体图，VOID 用 `meshCloud()` 采成点云 + `wire()` 抽成线框。所以"纸上画的"和"黑里亮的"永远是同一个东西，只是换了存在方式。

## 画风

- **线条**：全部是**画的线**，不是刷的线。1 px 级墨线、端点干净、圆角极小。直线是真直（不许有手抖），圆弧是真圆。唯一允许抖动的只有电弧本身（它就该抖）。
- **实体**：PLATE 里的零件用**正交 / 轴测投影的实体**画：按面法线分 5 档平色（不渐变、不描阴影），可见轮廓 1.4 px 墨线，内部棱 0.6 px，**被挡住的棱画成虚线**（工程图的隐藏线）——这就是"硬邦邦"的来源。剖面用 45° 剖面线，孔的轴向剖面加中心线。
- **光**：只有 VOID 有光。光是**加出来的**：密度堆到白，边缘留色，泛光把最亮处晕开。PLATE 里**什么都不发光**（参考片 `post.ts` 那条 0.85 阈值法则）。
- **质感**：纸上有一层极淡的纤维噪点（init 里生成一次，按世界坐标钉住，镜头平移时不游）；墨在实心大面积里改用网点（halftone），不用灰。VOID 有 0.03 颗粒。
- **动态节奏**：`drawRate` 12（一拍二）——但**只有电弧和闪烁用它**，机械运动（转台、滑轨、指针、装配）全部走连续的 `f.t`，因为机械是精确的、不是手绘的。大动作落在 `f.a.kick`，重音落在小节头。
- **镜头语言三件套**（都写在 `lib/look.js` 的一个 `MV.postFilter` 里，场景/时间线只报一个数）：
  ① **缓慢推近**：没有真正静止的镜头，2.6%–5.2% 按镜头时长自动；
  ② **局部放大 + 镜头跟随**（`insert`）：推进某个局部并一直跟着它——被跟的东西待在原处，周围往外扫；焦点由场景用 `LK.focus(f, x, y)` 每帧报出（跟着火头、笔尖、线尖、生长前沿），或由时间线给一个固定点；
  ③ **二维转三维**（`warp`）：整帧当成 3D 里的一块板子重投影（竖条投影 + 透视 + 影子），纸上的图会"立起来转过去"——用在进料口、落回纸面、归档三处。
  **推近有上限**：`TY.line` 每帧报出这一句歌词占的框，`safeZoom` 保证推近之后字还在画面里（贴边的句子会自动少推一点）。
- **没有真正静止的镜头**（参考片的特征）：每一条剪辑上挂着一台看不见的机器，以 2.6%–5.2% 的幅度、按镜头时长自动地**极慢推近**（外加几像素的横向漂移），让"静"的镜头也有动感。规则写在 `lib/look.js` 的 `MV.postFilter` 里一处，场景一行都不用改；跨切点有交叉淡化 / 转场的条目自动跳过（那里推近值会在淡化中途跳一下）。
- **冲击帧**（全片共用的修辞）：踩到底鼓时，允许单帧反转（纸 → 墨）或单帧白闪；持续 ≤ 2 帧。爆点（第 41 秒引爆、第 124 秒最后一击）用 3 帧负片。
- **禁止项**：不要紫色 / 青色霓虹赛博朋克；不要发光大脑；不要 Matrix 代码雨；不要镜头光晕汤；不要通用粒子星云；不要四角常驻遥测；不要给歌词加衬底 / 描边 / 光晕；不要写实人脸（人一律是剪影或零件）；不要"每章一色"。

## 调色板

**全片只有一个彩色：DeepSeek 蓝 `#4D6BFE`。** 其他全是中性（纸白、墨蓝黑、钢灰蓝）。

| 名称 | 色值 | 用途 |
|---|---|---|
| `void` | `#04060E` | VOID 的底（不是纯黑，偏蓝 6%） |
| `steel` | `#111C38` | VOID 里的暗结构、看不见的面 |
| `paper` | `#E9EDF7` | PLATE 的底（冷白，不是米白） |
| `paper2` | `#F5F8FF` | 纸上的高光区、被擦掉的地方 |
| `ink` | `#16224A` | PLATE 的主墨（结构线、文字、实体最暗档） |
| `ink2` | `#6B7BA8` | PLATE 的次墨：隐藏线、引线、辅助线、未唱到的字 |
| **`blue`** | **`#4D6BFE`** | **信号色**。唱到的词、主角零件的正色、唯一的强调。全片只此一彩 |
| `deep` | `#2337A8` | blue 的暗部（实体暗档、剖面线） |
| `ice` | `#A9BDFF` | blue 的亮部（等离子边缘、泛光边缘） |
| `hot` | `#EAF0FF` | 白热核心 / VOID 里的字。**永远锐利，永远不发光** |
| `arc` | `#C8DCFF` | 电弧的芯（电弧外层才是 blue） |

- **发光法则**：只有 `blue / ice / arc` 允许超过泛光阈值。`hot` 的字**绝不发光**（字一旦发光，画面就有两个亮点了）。一帧里只允许**一处**最亮。
- **稀有强调色**：**只有第 41.3–45.0 秒**（core 引爆 + singularity）允许出现 `#7FF3FF`（电青）——全片仅此一次、仅此 3.7 秒。一个色 = 一个记忆点。
- **明度反转**代替换色相：PLATE（亮底暗字）↔ VOID（暗底亮字）的来回就是全片的"换气"。副歌砸下来的一帧允许整帧反相。

## 字体

| 语域 | 字体 | 用途 |
|---|---|---|
| 人声 | **DIN Condensed Bold** | 歌词、标题、大字。窄、高、硬，工业感。需要更重时用 `strokeText` 同色描边 2% 加肥 |
| 机器 | **Menlo** | 尺寸数字、零件号、公差、引线、图表、标题栏。字距 +0.08 em，字号 12–22 px |
| 中文 | **PingFang SC Semibold** | 只出现在标题栏和章节号的第二行（雷铸 / 图纸 / 装配…），不超过 20 处 |

- 字号：display 字占画面宽的 **1/3 到满宽**（400–1100 px），字距 −0.02 ~ 0；小字 12–18 px（工程图上的真字就是这么大）。
- **颜色按语域给默认值**：唱到的字在 VOID 是白热、在 PLATE 是蓝墨——由 `TY.line` 的 `reg` 统一决定，任何 treatment 都不许写死 `LK.hot`（写了就会在纸上变成隐形字：1:35 那次 hook 就是这么丢的，`render.py qa` 的 `lyric-hidden` 量的就是这个）。
- **框里的字**：标题栏、表格、面板里的字一律用 `DR.cell` / `DR.titleBlock` 放；自己画的框用 `MV.box` 登记，`qa` 才查得到出框。
  两个框助手（`titleBlock` / `table`）都把**框和它的字包在同一个 `MV.group(...)` 里**：同一个 group 的字按"属于这个框"从严查
  （`box-tight` / `box-cross`），别的来源的字压上来只算撞车（`box-clash`，警告）。
  这条规矩抓出过一个真问题：`plot` 那根引线的落款正好**印在标题栏的 `BOLT.PLOTTER` 上**（两个字叠在一起），
  旧的按边距报法只说"离上沿 1.2 px"，改朝左引之后才干净。
- **歌词规则**：逐词同步，词在 `start` 那一刻变 `blue`（VOID 里变 `hot` + blue 芯），**绝不抢拍**；最多提前 0.4 s 用 22% 的 `ink2` 预示。一句的最后一个字离下一句 < 0.3 s 的（全片 2 处）允许压字，其余按 `lint.lineTail: 0.35`。
- **字号是有表情的，不是统一的**：喊出来的句子大到占满画面（眼睛那一镜 236 px、"Just transformers" 224 px），贴耳说的句子小到 54–78 px（中文屋、shoggoth、Sydney 终端）。`TY.line` 现在带**自动适配**：按要求的字号量一遍整句，超出安全宽度就整体缩小——所以"能多大就多大，但绝不越界"（`fit:false` 可关）。
- **有纯字的画面**：参考片里有一类镜头整幅就是字。本片三处：`ortho`（两条轴当基线，"Orthogonality" 横着、"thesis blues" 竖着，两条轴永不相交）、`show` 结尾（最后那一问三重回响，一次比一次小）、`stable` 的后半（后半句由一个光点划过写出来）。
- **歌词是画面的一部分，不是字幕**：每句的处理方式不同（见下面的表），位置也换（上三分之一 / 中央 / 贴着零件 / 骑在尺寸线上），**只有 4 句 hook 固定在下部横带**——那是它的记忆点。
- 文字离画面边缘 ≥ 96 px，且**不得压住主角**：可读性靠构图让位，不靠垫底。

## 贯穿母题

1. **THE CELL（核心总成）** —— 一台机器的图纸编号 `CELL-01`：外六角框 + 三道万向环 + 内球 + 12 片光圈叶片 + 6 根电极。它出现在**每一个**镜头里（局部或整体、图纸或发光），是全片唯一的主角。
2. **12 片光圈 = 眼睛**。开场是"你眼里的 AGI 火花"，第 33 秒变成"死神之眼"，第 132 秒它合上。同一份几何：`PART.iris(12)`。
3. **那根线**：绘图仪画出的第一根线 → 训练 loss 的坠落 → 导火索 → 电弧 → 最后一格还亮着的一根线。它在纸上是 `ink`，在黑里是 `blue`。
4. **标题栏**（图纸右下角）：全片每张图纸都有一个，写着零件号 / 比例 / 材料 / 修订版。它是这台机器的"病历"：REV A → REV F，比例尺从 1:1 到 1:10⁹。

## 已否决（不要再犯）

- **不给歌词加任何衬底 / 描边 / 光晕**（旧片试过三次，被否三次）。可读性靠构图让位。
- **不做四角常驻遥测**。全片每镜**最多一处**世界内读数，且必须贴着主角；标题栏只在 PLATE 出现，不在 VOID 出现。
- **不按章节换色相**。变化只有两条轴：PLATE↔VOID（明度反转）、体裁（实体图 / 点云 / 剖面 / 图表 / 织机 / 阵列）。
- **不用点云当"氛围尘"**。点云必须构成可辨识的形体（点要么在零件表面，要么在轨迹上）。
- **不在 PLATE 上发光**，也不在 VOID 里画实体填充（除了核心那一处白热）。
- **不用写实的人眼 / 人脸**：光圈叶片就是眼睛，人是剪影或零件。
- 不做"每句一镜"的字幕式剪辑；短句优先镜头内重构。

## 借了什么（对着 `docs/REFERENCE-pdoom-video.md` 的 A–L）

- **A** 一套调色板 + 明度反转变奏 → 全片 11 键、只有 `blue` 一个彩色、PLATE↔VOID。
- **B** 每镜一个 HERO 且给面积下限（≥30%）→ 镜头表的 HERO 列。
- **C** 砍掉四角遥测 → 全片每镜最多一处读数。
- **D** 一章一个体裁 → PLATE / VOID 两个体裁 + 实体图 / 剖面 / 图表 / 阵列 / 织机等子体裁，色不换。
- **E** display 字重与字距 → DIN Condensed Bold，400–1100 px，字距 ≤0。
- **F** 用构图给字让位 → 每镜写清字区，禁止垫底。
- **G** 歌词 treatment 表已有 → 保留并改写成本片的 13 种；位置不再全在下部横带。
- **H** "被写出来"的字 → `plot` treatment（笔迹长度 = 唱到的时间）。
- **I** 4K = 逻辑分辨率 + 物理像素分离 → 所有像素常量走 `PX()`，不写死 1080。
- **L** 记录否决理由 → 上面那段。

## 技术约定

- 每一帧只由 `f.t` 决定（`docs/ENGINE.md`）。不用 `Math.random / Date.now / performance.now`；用 `hash / mulberry32 / noise1`。
- 静态的画（纸纹、网点、机械底图、点云、线段缓冲）在 `MV.onInit` / 场景 `init()` 里做一次。
- 硬切落在小节头或唱到的音节上；大动作落在 `f.a.kick / f.a.snare`。
- 每改一个镜头：`uv run tools/render.py projects/pdoom-bolt stills --t …`，然后**用 Read 打开 PNG 亲自看**。
- 一个镜头一个文件（`scenes/<名字>.js`），共用几何在 `lib/`，`project.scripts` 里列出。
