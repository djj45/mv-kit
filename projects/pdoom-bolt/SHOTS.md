# SHOTS.md — 逐镜施工单

每一行是一个剪辑条目。**HERO = 这一镜能叫出名字的东西，必须占画面 ≥30%**；每个镜头最多一处"世界内读数"。
时间只写大概（准确切点由 `timeline.js` 按小节头和唱到的字算）。施工单里不写的时间，都在 `timeline.js` 里。

**两个语域**：`PLATE`＝纸 + 墨（`DR.paper` / `S3.draw`，纯 Canvas 2D，什么都不发光）；
`VOID`＝黑 + 光（`lmBegin(LK.palVoid())` / `lmPoints` / `lmLines` / `lmEnd`，只有蓝白发光）。
共用零件在 `lib/parts.js`（一份网格，两种画法）。歌词一律 `TY.line(g, f, {reg, …})`。

## 写作约定（每个镜头都要守）

1. `MV.scene('名字', { init(MV){…}, render(g, f){…} })`；`render` 要画满整帧，只依赖 `f.t`。
2. 静态几何（网格、点云、线段缓冲、纸、图案）在 `init` 里建好；`render` 里不要新建大画布。
3. PLATE：`DR.paper(g)` 打底 → `S3.draw / PART.*` 画实体 → `DR.dim / DR.leader / DR.micro` 加家具 → `TY.line(g, f, {reg:'plate'})` 收尾。
4. VOID：`lmBegin(LK.palVoid())` → `lmPoints / lmLines / lmGlow()` → `lmEnd(g, {bloom})` → 之后才画锐利的字（`TY.line(g, f, {reg:'void'})`、`lmTag`、`lmBig`）。
5. 一帧只允许一处最亮；PLATE 里不许发光，VOID 里不许画实体填充（核心那一处白热除外）。
6. 歌词：词在唱到时变色，不许抢拍；文字离边缘 ≥96 px，且不许压在 HERO 上。
7. 大动作落在 `f.a.kick`；小节头做重构图。用 `f.tick` 抖动、`f.t` 做机械运动。
8. 每个镜头做完必须 `stills` 出图并用 Read 打开看；构图不对就改。
