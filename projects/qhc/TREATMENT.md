## 一句话概念

**一只梅瓶的一生：他把她画在瓶上，自己画在瓶的另一面；一窑火把灰黑的素胚烧成青花，一场沉江把等待拉成几百年；直到它被连同月亮一起捞起，她空着的脸上自己浮出了笑。**

全片的画面都"画在瓷上"：主歌是入窑前的素胚世界（灰黑生料画在哑光坯体上），第 26 小节全乐队进来时是一窑火，副歌是烧成后的青花世界（钴蓝画在亮釉上）。歌词本身也跟着"烧"：主歌是灰黑色的字，副歌是带晕散的青花蓝字。

## 故事（四幕，跟着段落走）

1. **素胚（主歌 A，L1–L7）**：窑场作坊。年轻画师在素胚梅瓶上勾开光、画牡丹，牡丹花心点了一点红——像她的胭脂。夜里檀香的烟从冰裂纹窗格飘出去，有一瞬聚成她的身影。他在宣纸上起她的画稿，画到脸时停笔，把笔搁在笔搁上：**她的脸空着**。瓶的另一面，他已经把自己画成江边一个戴斗笠的小人。
2. **施釉·入窑（主歌 B，L8–L13）**：釉浆从瓶肩流下，盖住她的画像，一切"藏"进一层粉白；釉下那点红像含着的花苞，一呼一吸。她身上的披帛化成一缕烟从瓶上飘走，钻进窑门最后一道缝。窑门一块砖一块砖封上，他站在窑外，窑背的火眼一个个亮起来——那里面，他进不去。
3. **开窑·隔江（副歌前半，L14–L19）**：全乐队进来是窑火的白。硬切：瓶出窑，第一次是青花蓝，开光里的天空是天青色，开始落烟雨。镜头钻进"他"那面开光：斗笠小人立在船头等对岸；村子的炊烟飘过江，江越拉越宽，对岸的她只剩一个小影子。他在瓶底写下四字隶书款——给以后留的伏笔——然后把瓶放上小船推向对岸，瓶下沿的海水纹涨成真的浪，把船吞没。
4. **水底·传世（副歌后半，L20–L25）**：江底，天青色的水面落着雨，水藻长了又长，鱼游过，瓶上的斗笠小人还在等。某个夜里，绳网把瓶和水面上的月亮倒影一起捞起来，涟漪一圈圈晕开，整幅画的钴蓝也跟着晕开。最后瓶独自在一片釉白里自己慢慢转，转到她那一面停下：空了几百年的脸上，眼睛自己弯成两道笑，唇上落下全片最后那一点釉里红。

## 画风

- 参考方向（风格特征）：明代青花瓷的**纹饰画法**，不是水墨。"勾勒 + 分水"：细而均匀的勾线，线内用浓淡不同的平涂钴料填色；开光、缠枝、如意云肩、海水江崖这些瓷器纹样既当装饰也当画框和转场。人物用青花人物画的简笔：身段靠衣纹和姿态，脸只有轮廓。
- 线条：勾线笔的线，**粗细基本一致**（外轮廓 4–5 px，细部 2–3 px，1080p），带轻微手抖；起笔有一个小顿点。和《雨爱》的毛笔中锋 / 飞白刻意区分：这里没有粗细变化大的笔触，也没有泼墨。
- 分水（填色）：五个浓度的平涂（见调色板），**边缘略深**（分水笔的水干后积在边上），偶尔溢出勾线 ≤ 3 px。填色动画是"滴水分开"：从区域里一个点开始，湿边向外铺满，速度跟着拍子。
- 铁锈斑 / 晕散（只在烧成后）：重笔处和笔画末端有头浓色的小黑点（苏麻离青的"铁锈斑"），浓线周围 2–6 px 影淡色的晕。烧成前的灰黑生料没有这些，线更"干"、更颗粒。
- 质感：
  - 素胚：暖灰米色、哑光、细颗粒，瓶身有拉坯留下的淡横纹，**没有高光**。
  - 釉面：略带青的白；瓶身上一道柔和的竖向高光（相对镜头固定，瓶转时花纹从高光下滑过，靠这个读出"亮釉 + 立体"）；极细的釉中气泡和橘皮纹，只在近景看得出。
  - 进入开光后的全屏画面，仍然保留一层很淡的釉面反光缓慢斜扫，提醒观众"这是画在瓷上的"。
- 瓶上的透视：瓶身花纹按圆柱投影卷上去，靠近瓶边缘时横向压缩；转瓶 = 改变这张"展开图"的角度。
- 动态节奏：`drawRate: 12`（一拍二）驱动人物、烟、雨、浪、火和线条抖动；转瓶、推拉、上浮用连续的 `f.t`。整体偏静：主歌几乎只有笔在动，副歌才有明显的镜头运动。
- 禁止项：泼墨 / 飞白 / 宣纸晕染（那是《雨爱》的语言）；金色、翠绿、紫红等调色板外的颜色；龙凤、仙鹤、红灯笼、中国结、祥云贴图这类"中国风"套路；霓虹、bloom、镜头光晕、粒子星云；写实 3D 瓷器渲染；正脸特写和写实五官；不参考原版 MV 的情节与画面，也不画任何真实人物的样貌。

## 字体

- 歌词：**朱雀仿宋**（OFL，打包进 `fonts/`，@font-face 加载）；备选站酷小薇（OFL）。仿宋的清瘦和瓷器款识、题诗的气质接近，也和《雨爱》的楷书区分开。
- 瓶底款：「烟雨年製」四个隶书字**手绘成笔画路径**放在 `lib/mark.js`（要一笔一笔写出来，不用字体）。蚕头燕尾、字形扁、双圈内两列，右列「烟雨」、左列「年製」。一个虚构的年号，和天青等烟雨呼应。
- 排版：竖排、从右往左，像瓷器上的题诗，放在当前画面的留白处；字号 60–68 px；离边缘 ≥ 96 px。
- 歌词颜色跟着"烧"：主歌生料·浓，预示色生料·淡；副歌正浓，唱到后 0.3 s 内在字周围晕出一圈影淡；深色画面（S13、S14）里用影淡 / 釉白。
- 歌词规则：逐字同步——字在唱到时 0.12 s 显出，不能抢跑；可提前最多 0.4 s 以预示色显示。歌词层在最上，不被人物、釉幕、浪、火遮挡。

## 人物（原创）

- **他（画师）**：二十出头，瘦，头发挽髻裹一块布巾，交领短衫，干活时用襻膊把袖子系起；手指沾着料。只出现背影、四分之三背影、侧脸剪影和手的特写；脸最多三笔。只在前两幕和 S11–S12 出现，之后由瓶上的"画中他"代替。
- **画中他**：瓶上"他"那面开光里的小人：斗笠、蓑衣，立在小船船头或江岸，始终背对 / 侧对我们、望向对岸。
- **她（画中仕女）**：只存在于画稿和瓶上：高髻，髻边一朵牡丹，长披帛（会飘，是"一缕"母题的来源），长裙，手执团扇。**脸只有轮廓、没有五官**，直到最后一个镜头。
- 姿势库（`lib/people.js`）：他——坐案前执笔、停笔回望、窑前站立背影、手持笔写款、推船；画中他——船头站立（斗笠微抬 / 低头）、江岸站立；她——牡丹下侧立执扇、回身（披帛扬起）、最终的笑。

## 那只瓶（`lib/vase.js`）

梅瓶：小口、丰肩、瘦胫。纹饰从上到下：口沿回纹 → 肩部如意云肩（四瓣，内填缠枝）→ 腹部缠枝牡丹为地，**两个海棠形开光在瓶身正反两面**（A：她与牡丹；B：江岸孤舟与他）→ 胫部海水江崖 → 底部圈足与双圈四字款。
开光 A、B 相隔 180°：瓶上任何角度都**不可能同时看见两个人**：L17 唱的那段距离，其实只隔着一只瓶的直径。
瓶的纹饰做成一张展开图（在 init 里画一次，素胚版和青花版各一张），转瓶时按圆柱投影取景。

## 贯穿母题

1. **一缕**：檀香的烟（S3）→ 画稿上的一根线（S4）→ 她的披帛化成的一缕烟（S7）→ 窑的烟、村子的炊烟（S10）→ 海水纹的浪头（S12）→ 月下的涟漪（S14）。全都用同一套青花云纹的卷曲笔法画。
2. **空白的脸**：画稿上搁笔留空（S4）→ 釉下看不清（S5–S6）→ 最后自己浮出笑意（S16）。
3. **一点釉里红**：牡丹花心（S2）→ 釉下的一点暖（S6）→ 她的唇（S16）。它不守"烧成"的规则，因为它是她。
4. **两面开光**：他和她在同一只瓶的两面，永远不同框。
5. **生料 → 青花**：第 26 小节之前的一切是灰，之后是蓝；歌词同样。
6. **留白的月**：水面上的月亮是釉白的圆，和结尾那片釉白相接。

## 技术约定

- 每一帧只由歌曲时间 t 决定（见 docs/ENGINE.md）。
- 新风格包 `kits/qinghua.js`（与歌无关、可复用）：`QH`（调色板常量，素胚 / 青花两套）、`paintBiscuit`（素胚质感）、`paintGlaze`（釉面高光、气泡、橘皮纹）、`qhLine`（勾线：顿点、手抖、铁锈斑）、`qhFill`（分水：边缘积色、从一点铺开的填色动画）、`qhHalo`（晕散）、`cylWrap`（展开图 → 圆柱投影，带旋转角）、`glazeCurtain`（施釉垂滴擦除）、`qhPatterns`（回纹、如意云肩、缠枝、海水江崖、云纹、火焰纹）、`qhColumn`（竖排逐字"烧出"的歌词）。纸纹和竖排歌词可以从 `kits/ink.js` 的 `paintXuan` / `inkColumn` 改出来。
- 项目 `lib/`：`font.js`、`vase.js`（梅瓶轮廓 + 两张展开图）、`workshop.js`（作坊、冰裂纹窗、香炉、案、笔搁、画稿）、`kiln.js`（龙窑、窑门砖、火眼、窑内火焰）、`river.js`（开光里的江南：两岸、船、村子、炊烟、雨）、`water.js`（江底、水藻、鱼、水面、月、涟漪、绳网）、`people.js`（姿势库）、`mark.js`（四字隶书款的笔画路径）。
- 性能：素胚 / 釉面质感、两张瓶身展开图、作坊和窑的静态背景都在 init 里画好；每帧只做圆柱投影取景 + 画动态的线、填色、烟、雨、浪。
- 硬切：第 26 小节头（进窑火）和 L14 第一个字（进青花），其余都是瓷器自己的转场——转瓶、入 / 出开光、釉幕、浪涌、晕散。大动作落在底鼓或小节头（f.a.kick）；砖、浪、火焰抖动踩拍。
- 每个镜头做完：`uv run tools/render.py projects/qhc sheet --cuts`，打开拼板逐张检查。
- 音频结尾：终点 1:33.70 是第 43 小节头，之后间奏继续，`project.audioFadeOut` 设为 2.0 s。
