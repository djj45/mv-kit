# 《雨爱》MV — 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> 区间：第一段主歌前一小节 → 第一遍副歌结束（约 0:12.85 – 1:42.86，30 小节，80 BPM，4/4，一小节 3.0 s）。

## 一句话概念

**一幅在雨里慢慢展开的水墨长卷：每一滴雨都是落在宣纸上的一滴墨。**
主歌是窗外的墨云与窗内的她；预副歌是离开、把眼泪收进心里；副歌时墨滴落满纸面，她和他各自在长卷的一端看同一场雨；最后雨水把墨云洗开，天空留白出一道弧——黑白画里的彩虹。两人在同一道弧下，但不相见。

## 画风

- 参考方向（风格特征）：中国写意水墨 + 白描人物。宣纸、湿墨晕染、飞白、大面积留白；人物极简，靠姿态和剪影说话。
- 线条：毛笔中锋，笔压决定粗细；起笔藏锋（圆头），收笔出锋（尖尾）；干笔处飞白（多根"笔毛"细线按噪声断开）。人物用白描单线，衣纹少而准。
- 阴影 / 光：不用硬阴影、不用光源。远近靠墨阶：远景清墨、中景淡墨、近景浓 / 焦墨。雨大时"水破墨"——墨被水冲淡、冲散、留下水痕。
- 质感：暖白生宣，纸纤维 + 细颗粒（init 里生成一次）；湿墨洇开时边缘不规则、外圈略深（水痕）；干后的墨微带纸纹。
- 动态节奏：`drawRate: 12`（一拍二）驱动人物、雨线、笔触抖动；镜头运动（手卷横移、推拉）用连续的 f.t。晕染大小是"落下后经过的时间"的函数：r(age) = r∞·(1 − e^(−k·age))。
- 手卷方向：**她的镜头从右往左横移**（传统手卷展开方向），**他的镜头从左往右**。
- 人物墨色规则：**她用浓墨、线条实**；**他用淡墨、飞白多、线条虚**——他属于回忆那一侧。
- 禁止项：任何颜色（包括红印章）、霓虹 / 发光 / bloom、粒子星云、3D 质感、写实雨、镜头光晕；红灯笼、仙鹤、宝塔、竹林剪影等"中国风"套路；正脸特写。

## 字体

- 歌词：**马善政楷书**（Ma Shan Zheng，OFL，打包在 `fonts/`，@font-face 加载）。
- 辅助：无。全片不出现 UI 或标签文字。
- 排版：**竖排、从右往左**，像画上的题款，放在当前画面的留白处（通常右侧或左上）。字号约 64–72 px；句中有空格处拆成两列。"Rainie Love"横写，小一号，贴在列旁。
- 歌词规则：逐字同步——字在唱到时像墨一样洇出（0.15 s 从清墨洇到浓墨，边缘带一点晕），不能抢跑；可提前最多 0.4 s 以极淡清墨预示。离画面边缘 ≥ 96 px，不被人物或雨遮挡（歌词层在最上，雨线在字周围自动让开）。

## 人物（原创）

- **她**：长发低束、发尾用飞白散开；素色长开衫、长裙，现代装束。以背影、侧脸、剪影为主，面部只用 2–3 笔（眉、闭眼或低垂的眼线）。
- **他**：短发，白衬衫，瘦高；只以背影、侧脸出现，淡墨虚线。
- 共用姿势库（`lib/`）：她——坐窗边、低头、起身行走、侧脸呵气、撑伞站立、抬头；他——站立背影、侧脸、抬头；两人共伞（回忆，淡墨）。

## 贯穿母题

1. **一滴墨 = 一滴雨**：开场一滴 → 副歌满屏 → 结尾被水洗开，露出留白的弧。
2. **窗**：木格窗把"窗外的雨"和"窗内的她"隔开，多次用作画框。
3. **玻璃上的水汽**：记忆显影的地方——雾里浮出淡墨回忆，随水珠流下。
4. **一条不断的墨线**：从回忆流下的水痕变成一笔墨线，穿过长卷，把她那一端和他那一端连起来。
5. **留白的弧**：黑白画里的彩虹。

## 技术约定

- 每一帧只由歌曲时间 t 决定（见 docs/ENGINE.md）。
- 新风格包 `kits/ink.js`（与歌无关、可复用）：`paintXuan`（宣纸纹理）、`inkStroke`（笔压 / 藏锋出锋 / 飞白）、`inkWash`（晕染块 + 水痕边）、`inkBloom`（按 age 生长的墨滴）、`inkRain`（分层雨线）、`inkColumn`（竖排逐字洇出的歌词）、`inkWipe`（墨染转场）、常量 `INK`（五墨色 + 纸色）。
- 项目 `lib/`：`scroll.js`（预先画好的超宽山水长卷，横移镜头在上面取景）、`girl.js`、`boy.js`（姿势库）、`window.js`（木格窗、玻璃水痕）、`eaves.js`（屋檐、水洼）。
- 性能：纸纹、长卷、晕染贴图都在 init 里做好；每帧只合成 + 画动态的墨滴和雨。
- 硬切只有镜头 7；其余都是墨染 / 水洗 / 横移（用 fadeIn 重叠 + 场景内的墨染遮罩）。镜头 1–4 是一个连续的长镜头。大的墨滴落在底鼓或小节头（f.a.kick）。
- 每个镜头做完：`uv run tools/render.py projects/yuai sheet --cuts`，打开拼板逐张检查。
- 音频结尾：导出区间终点在 1:42.86 小节头，之后间奏继续，需要把片尾的音频淡出从 0.2 s 延长到约 2.5 s（给 render.py 加一个 `project.audioFadeOut` 参数）。
