# 《field-demo》— 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> 这是一份**样张**（不是 MV）：没有歌，占位歌词按 120 BPM 的网格摆好，节拍器就是 `project.bpm`。写它的目的是把
> `kits/solid.js` 和 `kits/sim.js` 放在 lumen 上跑一遍——三种"场"，一个镜头一种。

## 一句话概念

**看不见的规则，怎么自己长出形状。** 磁力线没人画过，它是铁屑一根根转过去、又两两相吸聚成链以后的样子；
极小曲面不是雕出来的，它是"零集"这个名字的样子；鸟群没有领队，形状是两千多只鸟只看身边十来只的结果。
三个镜头，三次"从规则到形状"。

## 画风

- 参考方向：不是某部作品，是这类画面本身的特征——**发光数据 / 终端科幻**（lumen.js）：纯黑底、加色叠加、
  细线和点云、密处烧成白、边缘留色、泛光把最亮的地方晕开；受光的面只在要"摸得到"的时候出现（磁铁、曲面），
  而且面也是用光画的：暗的本体 + 亮的边光和高光，几乎没有漫反射的灰面。
- 线条：lumen 的线是"光"不是"描边"：1–2 px、无抗锯齿描边感、暗处几乎看不见，聚到一处才成线。
- 阴影 / 光：没有环境光。形体靠**密度**（叠加多少次）、**大小**（近大远小）、**景深**（失焦的点变成大而淡的光斑）
  和**遮挡**（solid.js 的深度：点线可以躲到实体和光线步进的结构后面）。
- 质感：`post.grain 0.035`，`vignette 0`（暗角在 `lmEnd` 里按调色板做）。字是清晰的等宽小字，画在泛光之上。
- 动态节奏：没有真正静止的镜头。每个镜头内部按"事件—停住"排：冲一下、然后完全停住让人看一眼（`gyroid` 里
  一拍冲一间、然后死停）。点阵不要一直闪——闪得均匀，事件就不突出了。
- 禁止项：不用纯灰的漫反射面；不做匀速平移（像屏保）；不做"所有东西一个速度"的动画；数字不凑（HUD 里的
  步数、粒子数、速度都是真的）。

## 字体

- 歌词：`lmTerminal`（左下终端，`JetBrains Mono` 30 px，`> ` 提示符 + 方块光标）：词在它自己的 start **整词**
  打出、落下时闪一下强调色，旧行整体上移变暗。切点之前唱完的句子不带进镜头。
- 辅助：`lmHud`（四角细框 + 镜头号 / 时间码 / 名字 + 右上键值读数 + 右下注脚，`lmFlick` 通电闪烁）、
  `lmSection`（左上章节号：`01 / 03 —— 磁场 IRON FILINGS`）、`lmCode`（左中的公式，带行号）、
  `lmLabel`（磁极的 N / S 引线标注）。
- 歌词规则：逐词同步，词在唱到时出现，不抢跑；离边 ≥ 96 px；一句的最后一个字完整停留 ≥ 6 帧。

## 贯穿母题

1. **同一件事的三次"通电"**：磁铁闪烁通电（`lmFlick` + 白色 `flash`）→ 曲面从远到近一层层亮起来 → 鸟群被一个
   亮点捅开。三个镜头都由"一个东西开始起作用"开头。
2. **粒子数进 HUD**：3 600 根针 / 2 600 只鸟 / 150 步光线步进——每一次都把"这是算出来的"摆在画面角上，
   而且数字是真的（`s.bmax` 是这一步针脚下的最大场强，`s.sp` 是这一步算出来的平均飞行速度）。
3. **深度的用法**：`dipole` 的铁屑躲在磁铁后面（`occlude`）；`gyroid` 的尘埃和样品躲在墙面后面；`flock` 没有面，
   深度靠大小和密度。三镜连起来是"光有了厚度"这件事的三种程度。

## 角色

没有角色。主体是场本身：`MV.focus` 报的是磁铁 / 铁屑 / 磁力线 / 球 / 样品 / 鸟群 / 闯入者，名字和 timeline 的
`reads` 第三列一一对应（qa 的 `read-unled` 就是在量这个）。

## 技术约定

- 每一帧只由歌曲时间 t 决定（`Math.random / Date.now` 一律不用；随机数来自 `mulberry32`、`hash`、`SIM.seed`）。
- 两个模拟（`dipole`、`flock`）走 `SIM.make`：状态 = 镜头开头 init，再按固定步长 1/60 算到 t，所以导出乱序、
  运动模糊的子帧、从中途开始的块都对得上。
- 分辨率：全部按设计尺寸 1920×1080 画；`--4k` 是同一份代码重新画一遍（字和线是矢量重绘，不是放大）。
- 全局名字：多个 `<script>` 共享作用域，三个场景的顶层常量分别加 `DIP_ / GYR_ / FLK_` 前缀；这个项目没有 `lib/`。
- 画面上固定的字（章节号、HUD、代码块、磁极标注）都包进 `MV.decor()`：它们是画面的一部分，不是歌词——
  代码块里出现的 "wall" 会被 qa 当成跨镜头带过来的歌词。
- 保留的 qa 警告：`type-flat / type-band`（全片一种歌词、都在下半部分）。这是样张有意的：三个镜头的构图都把
  左下留给终端，字号统一。正式的 MV 里在副歌用大字 / 拆字 / 粒子拼字把字号和位置拉开。
