# field-demo — 样张：三种"场"

不是 MV（没有歌：歌词是占位的原创句子，节拍是 120 BPM 的网格），是 lumen + solid + sim 上的三个镜头，一个镜头一种"场"——看不见的规则怎么自己长出形状。18 秒，每镜 3 小节。

| 时间 | 镜头 | 调色板 | 演示 |
|---|---|---|---|
| 0–6 s | `dipole` | ember | **磁场**：一块条形磁铁埋在 3 600 根铁屑里。每根铁屑是一根针：受 B×m 的力矩转向磁力线（针没有头，对齐的周期是 π）；每一对邻居之间是**偶极作用力** F ∝ [(1 − 5c²) r̂ + 2c û]/r⁴（沿轴相吸、并排相斥——这才是把铁屑串成链的原因）；整体朝 **∇\|B\|²** 爬，所以两个极都积铁屑。唱到 "under" 磁铁通电，所有针转过来、串成线；第 2 小节第二块磁铁从右边滑进来（异性极相对），线重排成从一个极跑到另一个极；第 3 小节同一组磁极在三维里积分的磁力线，一根根金色弧线从盘面长出来 |
| 6–12 s | `gyroid` | ice | **曲面**：光线步进的极小曲面 gyroid（`smShader`）：sin x·cos y + sin y·cos z + sin z·cos x = 0 加厚成板、切进球壳（中间是空的，镜头才进得去）。从黑里长出来 → 表面在镜头要穿的地方**开一个洞**（减集），进去 → 在迷宫里按拍走：一拍冲一段、然后**死停** → 从另一处开洞爬出去，两个洞都合上：一整张面，没有边。球里面按"镜头进去多深"压暗，墙靠边光和高光读形状 |
| 12–18 s | `flock` | rose | **群体**：2 600 只椋鸟，没有领头的。每只只看得到身边 0.14 u（约 10 只）：对齐、聚拢、分离，加一个**中程推力**（0.13 u 内的邻居轻轻推开：群内部互相抵消，洞边只有一侧推，就把鸟推进洞里），外面一圈软墙兜住。平静时悬着慢慢动；一个亮点从左边高处俯冲、贴着薄片匀速横穿鸟群，脚下清出一个跟着它走的洞，周围的鸟受惊飞快；它离开后洞靠鸟自己的规则合上，鸟群再慢下来 |

```sh
open projects/field-demo/index.html
uv run tools/render.py projects/field-demo sheet --cuts
uv run tools/render.py projects/field-demo
```

用法见 `docs/ENGINE.md` 的 solid.js 和 sim.js 两节。

## 量具：不看图的那部分

模拟对不对，看图看不出来（铁屑垂直于磁力线和顺着磁力线，两种画面都"挺好看"）。`tools/` 里的脚本用 node 的 `vm` 直接加载**真的在跑的那段场景代码**（`engine/core.js` + `kits/sim.js` + 场景文件，`SG` / `LG` 打桩），跑到指定时刻再量：

```sh
node projects/field-demo/tools/dip.js 3.6             # 针和 B 的平均 |cos|；按距离分段的邻居方向（随机 0.637，高于它 = 沿 B 成链）；四极 0.3 u 内的铁屑数；一步多少毫秒
node projects/field-demo/tools/flk-uniform.js 0.2     # 从上往下看，鸟群轮廓内 0.2 u 格子的鸟数：p10/中位（洞、走廊）、p90/中位（线、脊）、稀格占比
node projects/field-demo/tools/flk-vacuole.js 0.3     # 闯入者在鸟群上方时：它脚下、周围一圈、它 0.3 / 0.6 / 1.0 s 前经过的地方，各是中位密度的几倍
node projects/field-demo/tools/flk-clusters.js 0.15   # 连通的团数、5–95 % 外形尺寸、每只鸟的邻居数
uv run python projects/field-demo/tools/lum.py projects/field-demo/out/stills/t0009.000.png   # 整帧平均亮度、高光占比
```

**主量具是 `flk-uniform` 和 `flk-vacuole`**，它们按**密度**量。另外几个只作参考，各有盲区（做这个镜头时一个个踩过）：`flk.js` 的"离重心近的鸟占比"会被两团夹着空重心骗；`flk-clusters` 的单链聚类会被两片之间的一座窄桥骗；`flk-holes` 只要格子里有一只鸟就算"填上"，变稀的走廊看不出来；`flk-bands` 只查挤成线、不查变稀。`flk-hawk.js`、`flk-frame.py` 是中间几轮用过的辅助脚本。

## 做的时候踩到的坑（写新镜头时照着避开）

**dipole**
- **力矩的符号**：`cross = cx·uy − cy·ux` 是 sin(θ_B − θ_针)，所以 `−K·2·cross·dot` 的稳定点在 90°——铁屑会垂直于磁力线站好，画面上是一圈圈绕着磁极的"指纹"，一样挺好看。量出来平均 \|cos\| 0.018，改符号后 1.000。
- **铁屑朝 ∇\|B\|² 爬，不是顺着 B 漂**：顺着 B 漂会把 N 极扫空、全堆到 S 极（四极 0 / 1182 / 0 / 846）。∇\|B\|² 可以解析地算：单极子那项的 `k = q/ρ³` 本来就有，`q/ρ⁵ = k/ρ²`，三个累加器就够。
- **成链要用逐对的偶极力**：让每根针"朝邻居重心靠拢"是沿 B 压缩，铁屑会并排挤成**横跨**磁力线的带（邻居方向 0.50–0.53，低于随机）。偶极力本身又会相分离（1/r⁴ 把铁屑塌成一颗颗团），加一个 ∝1/r² 的各向同性软斥力和一点抖动（"敲盘子"）才是链是链、缝是缝。
- **起跑价**：`SIM.make` 的镜头每个导出块都从镜头开头重跑。17 000 根针一步 57 ms，3 600 根 5.9 ms；这个尺度上看不出差别。

**gyroid**
- **`smShader` 里开洞是减集** `max(d, r − |p − door|)`；写成 `min` 是在球上粘一个实心球，镜头还会卡在里面（整屏过曝）。洞的位置在 `init()` 里沿镜头路径找"第一次 / 最后一次穿过中面"钉住，不要每帧跟着镜头走。
- **死停**：停的区间用 `linear` 关键帧其实还在走；迷宫的转动挂在 `lt` 上也在走。停的那段 `u` 只走千分之几，转动写成 `u` 的函数，qa 的速度行才看得到停。
- **镜头进到结构里面时整屏是亮面**：按"进去多深"把底色、辉光和小节脉冲压下去，留边光和高光。

**flock**（这一镜改了很多轮，大部分时间花在下面这些上）
- **初始位置和"保持离重心多远"都会做出甜甜圈**：空心壳初始化、偏好半径的力、恒定的速度下限（圆心的鸟被踢走）、切向力（越转越大）都会把中间掏空。实心扁盘初始化 + 软墙 + 速度下限随半径缩放。
- **整体旋转会带着伤口一起转**：任何写在世界坐标里的"往某条线拉"的力，几秒后就在顺着伤口拉。
- **按三维距离推鸟会把鸟顶出薄片**，掉出去的鸟再也回不来，洞永远填不上。闯入者的气泡按从上往下看的圆盘推。
- **硬拉伤口合上会把鸟压成一条线**（一道笔直的亮线夹两条空带）。合上应该是鸟自己的规则做的。
- **鸟群内部要有压力**：只有贴身的分离（0.065 u）时，鸟群停在自然间距上谁也不碰谁，洞边没有任何力把鸟推进去。加一个 0.13 u 的中程推力：群内部成对抵消，洞边只有一侧推——像装在容器里的气体，软墙就是容器壁。
- **按"绝对邻居数"写的阈值要跟着密度重定**：`FLK_LCALM`（少于几个邻居算"落单"：聚拢减弱、速度上限放宽）原来是 18，那是鸟群每只有约 20 个邻居时定的；加了中程推力以后每只只剩约 10 个，93–100 % 的鸟一直算落单，鸟群从头到尾 0.32–0.46 u/s 没有一刻平静（qa 报 `one-speed`）。改成 6 之后落单的只剩洞边那 5–9 %。
- **闯入者要匀速横穿**：缓动最快的那段在中间，洞会落后它 0.3 s。
- **量具也会骗人**：上面"参考"那几个量具的盲区，每一个都让一版"数字达标、画面不对"的代码过了关。还有一条：最后一次改代码之后，所有数要重跑一遍再写进文档。

## qa 和速度

- 整片 `qa`：0 错误，2 条警告 `type-flat / type-band`：全片只用了一种歌词（左下终端，30 px）。这是样张有意的——三个镜头都在画面的下半部分留了位置给终端；正式的 MV 里在副歌用大字、拆字或粒子拼字把字号拉开。三个镜头单独跑 `qa --from … --to …` 都是 0 错误 0 警告。
- 速度行（设计 px/s，每 1/6 s 一格）：dipole 静 7–22 ↔ 通电 / 滑入 / 弧线 166–195；gyroid 停 28–46 ↔ 冲 324–356；flock 悬停 38–53 ↔ 被打中 154–183。
- 这台机器（Apple M5，ANGLE/Metal）：`check` 渲中间一帧 dipole 239 ms、gyroid 115 ms、flock 316 ms（都含从镜头开头跑模拟）。全部按 1920×1080 设计尺寸渲染，`--4k` 是同一份代码。
- 文字后面由 **lumen 的文字助手默认清底**（`docs/ENGINE.md`「字自己让出位置」）：金色弧线、流线、球面从字后面经过时在字前淡出。画面里固定的字（章节号、HUD、代码块、磁极标注）包在 `MV.decor()` 里——代码块里的 "wall" 会被 qa 当成跨镜头带过来的歌词。
- flock 每 5 只鸟垫一个大而淡的软点（haze）：没有它鸟群像撒了一把沙，有它轮廓读得出"一整片"。这是画面的选择，qa 不需要它。

## 写 TREATMENT 时可以照抄的画风要点

- **规则**：lumen 的"一切都是光"不变——黑底、叠加、泛光；面只在"要摸得到"的时候出现（磁铁、曲面），而且面也是用光画的：暗的本体 + 亮的边光和高光。
- **看不见的东西要有一个可见的动作**：磁铁"通电"那一下要有闪烁和闪光，铁屑转向要有过冲和抖动（先摇再定），曲面生长要从远到近一层层亮。
- **模拟要有初始态**：先给一秒"什么都不对"的画面（灰雾、还没长出来的球、悬着的鸟群），再给原因（通电、拍点、闯入者），然后让结果自己长出来。每一步落在拍上。
- **数字进 HUD，而且要真**：粒子数、步数、周期、\|B\| max（这一步针脚下最强的场）、邻居数、实时平均速度——都是这一步算出来的；代码面板写的是模拟实际遵守的全部规则。
- **一个镜头一种调色板**（ember / ice / rose），三个镜头合起来是一支片子的三章：`lmSection(g, i, 3, '磁场', 'IRON FILINGS')`。
