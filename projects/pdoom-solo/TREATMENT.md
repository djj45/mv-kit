# 《减版》MV — 创意方案 / 风格圣经

> 先写这份文档，再写代码。每个镜头的代码都以它为准；改风格就先改这里。
> 片名：**《减版》**（reduction block：一块版，刻一次、印一次，再刻掉更多，再印——版只会越来越少，永远加不回来。）

## 一句话概念

**整支片子是一块正在被逐次刻掉的木刻版：这首歌每往下唱一句，版上就少一样东西。**
末日不是多出来什么，而是**再也加不回去**——所以画面越到后面越空，副歌第四次（全曲最响）看到的是那把刻刀本身，之后只剩一张白纸。

这首歌的四次副歌能量是 0.70 → 0.80 → **0.03**（第三次副歌整段没有鼓，是全曲最安静的副歌）→ 1.00。片子的减法曲线跟它对齐：副歌一印得满满当当，副歌二开始出现刀口，副歌三版几乎空了（音乐也空了），副歌四刀最大、画面最黑，然后全白。

## 画风

- **参考方向（只写风格特征）**：欧洲/日本现代**木口木刻与麻胶版画（relief print / linocut）**的印刷品本身——不是"画成版画风"，而是**镜头拍的就是一张刚印出来的版画**：大面积实黑（油性印墨，暖调、有厚薄）、刀刃铲出来的白（留白不是画上去的白，是**刻掉**的部分）、成组的平行排线做中间调、纸是手工棉纸。
- **线条**：
  - **刀口线（gouge）**：宽 8–18 px，两头尖（V 形刀），边缘有微小毛刺；这是"留白"的形状，不是描边。
  - **轮廓线（contour）**：3–4.5 px 黑，粗细沿笔画变化 ±30%，按 `f.tq` 定格抖动（line boil），绝不用等宽圆头线。
  - **排线（hatching）**：组距 9–14 px 的黑线做暗部；线被刻断的地方插入白色缺口。
  - **木纹（grain）**：1.5 px 灰线，方向统一水平 ±6°，**钉在世界坐标上**，镜头平移时不游动。
- **阴影 / 光**：没有渐变阴影。明暗只有四档：**纸（0）→ 排线（1）→ 交叉排线（2）→ 实黑（3）**，加一档"残影灰"（上一次印的淡痕）。
- **质感**：① 纸：暖白棉纸的纤维、压痕、极小的污点；② 墨：实黑区里有随机**缺墨小孔**（贴图在 `init` 里做好一次，按 `f.tq` 换两张），边缘有"咬纸"毛边；③ **套印错位**：红版/蓝版相对黑版错开 3–6 px，在轮廓边缘露出来，`f.t` 让它极缓慢地漂 1–2 px。
- **动态节奏**：`drawRate: 12`（一拍二）。角色动作、刀的运动、线条抖动都走 `f.tq` / `f.tick`；镜头运动走连续的 `f.t`。**大动作落在 `f.a.kick` / `f.a.snare` 上，切点落在小节头或唱到的音节上。**
- **禁止项**：
  - 不用渐变阴影、不用高斯模糊做柔光（这不是版画的语法）。
  - 不做成"黑色剪影 + 白描边"的假剪纸：实黑、排线、刀口白三者的面积比例要一直在。
  - 不用赛璐璐分色、不做发光、不做数据可视化、不做蓝图/网格纸、不做安全标识牌。
  - 不加胶片划痕 / 漏光 / 老电影抖动。
  - 不描任何现有作品的角色。人形一律是原创的木刻小人（一根脊柱 + 两条腿 + 一双手，没有五官，脸是一块留白）。

## 调色板

| 名称 | 色值 | 用途 |
|---|---|---|
| ink | #14110E | 黑版：人、身体、世界的一切实体；大面积实黑 |
| paper | #E9DFC9 | 棉纸：留白、被刻走的地方、纸边；也是"全白"结局 |
| red | #B93327 | 红版（第二块）：**刀口**、唱到的关键词、副歌的 P(doom)；只做强调，面积永远 < 10% |
| blue | #2B4A6E | 蓝版（第三块）：**"它"**——AGI、机器、优化器、GPU；凡是"不是你"的东西都用蓝 |
| ghost | #9E957F | 残影灰：上一次印的淡痕、木纹、颗粒、还没唱到的字 |
| warm | #4A4038 | 半调：排线的深色档，在黑与纸之间做一档 |

**配色规则（每镜都要能一眼读出）：黑 = 我们；蓝 = 它；红 = 刀口 / 关键词。** 一帧里红的总面积不超过 8%，蓝不超过 25%。

## 字体

三档，都是 Mac 自带：

| 档 | 字体 | 用在哪 |
|---|---|---|
| 歌词（主档） | `"Superclarendon"`（slab serif，700/900） | 绝大部分歌词：刻在黑里的白字、印在物体上的字、巨字 |
| 标注 / 版边字 | `Menlo`（等宽，500） | 版边标注、编号、刻度、门牌上的字；小档 34–44 px |
| 巨型词 | `Impact`（压缩黑体） | 副歌的巨字（P(DOOM)、FOOM、OMEGA POINT）；190–240 px |

- **歌词规则**：逐词同步，词在 `start` 时出现 / 高亮，不抢跑；最多提前 0.4 s 以 `ghost` 预示。文字离画面边缘 ≥ 96 px（`qa.margin`）。每个词单独 `fillText`。
- **字号分档**：标注 34 · 小 44 · 中 66–84 · 大 96–132 · 巨 190–240（最大 / 最小 ≥ 3 倍，实际 240/34 ≈ 7 倍）。

## 歌词怎么出现（7 种，各用在哪）

| 代号 | 名字 | 做法 | 用在哪 |
|---|---|---|---|
| **CARVE** | 刻在黑里 | 场景层，白色（paper 色）字从大面积实黑里"铲"出来，字缘带刀口毛刺；整句报 `MV.keep` | 主歌主力：黑块占画面 ≥ 45% 的镜头 |
| **STRIP** | 纸带 | 屏幕层 `MV.overlay`，字印在一条 paper 色 / red 色的窄条上（垫底），唱到的词 ghost→ink | 画面忙、主体会压到字上的镜头 |
| **MONUMENT** | 巨字 | 190–240 px，几乎占满宽；关键词走红版，其余 ghost→ink；`MV.overlay` | 副歌的 P(doom)、FOOM、OMEGA POINT、self-upgrade |
| **TYPE** | 活字落下 | 每个词在 `start` 时从上方 40 px 落到基线（`outCubic`，0.18 s），落定后不再动 | Forward MLP backward repeat、Hundred thousand GPU |
| **LABEL** | 版边标注 | 34–44 px Menlo，印在画面边缘或物体标签上；`MV.within(owner)` 从严 | 安静段落、门牌、刻度、qa 需要小档的地方 |
| **ON-OBJECT** | 印在东西上 | 字画进牌子 / 纸袋 / 门牌 / 刻度尺的 `MV.group`，跟物体一起动 | 中文房间、纸袋、开关牌、SAFETY FENCE |
| **ERASED** | 只剩一个词 | 整句先出现，唱到最后一个词时前面所有词被"刻掉"（白色刀口覆盖，字消失） | 副歌三、副歌四 |

## 贯穿母题

1. **那块版**：每一次副歌都是**同一个画面**——一块放在压印台上的版，上面刻着四排一模一样的小人，最前面一个（主角）手里握着刻刀。四次副歌是同一张图被刻掉得越来越多的四个状态。
2. **那把刀**：V 形刻刀。它出现在小人的手里、黑团的边上、副歌四的整幅画面；红版只描刀刃。它每出现一次，画面里就少一样东西。
3. **对版十字线**：印刷时的套准记号。前奏、副歌三、尾奏都出现；最后一次出现时它周围什么都没有了。
4. **主角小人**：一根脊柱 + 两条腿 + 一双手、脸是留白。他在每个段落都出现，身上的刀口越来越多。

## 不要做的（我最容易犯的错，做的时候对照）

1. **把整首歌做成字幕**：每句都排在底部一条横带上。→ 每镜先在表里定横带，写完统计；≥ 1/3 的歌词必须印在画面里的东西上或刻在黑里。
2. **木刻画成"黑剪影 + 白描边"**：忘了排线这一档中间调。→ 每个有实黑的镜头至少一处排线。
3. **镜头只会缓推**：忘记 insert / warp / CAM.keep 的位置，或者全片推得太猛。→ 按配额表分配，条目上写清 `at/dur/amt`。
4. **歌词字号一档到底**：写完统计 max/min，不达标就调。
5. **忘了每帧报 `MV.focus`** → `focus-out` 错误。主体一定最后报。
6. **字压在同色的黑上** → `lyric-touch`。刻在黑里的字必须是 paper 色，且黑块里没有 paper 色的线穿过字。
7. **切点把上一句带进新镜头** → `lyric-carryover`。一律用 `lyrics.lineAt(f.t, f.from)`。
8. **在 `render` 里累积状态 / 用 `Math.random`** → 导出时帧错乱。全部用 `hash / noise1 / mulberry32`，位置写成 t 的函数。
9. **大面积 `filter: blur()` / 每帧新建大画布** → 卡。所有贴图（缺墨孔、纸纹、木纹）在 `init` 里做好。
10. **忘了 `MV.keep` / 场景层歌词被推出去** → `text-cut`。屏幕层歌词不需要 keep；场景层的必须报。
11. **转场说不出理由就用了 `fadeIn`** → 只有 S14、S44 用 warp，其余硬切。
12. **多个 scene 文件顶层 `const` 重名**（共享全局作用域）→ 项目内顶层常量一律放进 `WD` 或加 `PD` 前缀。
13. **把"末日"画成一堆爆炸/骷髅**：这支片子里最可怕的是**空白**。减法要靠"少了什么"演，不是靠"多了什么"。
14. **红版用超**：红只给刀口和关键词，一帧别超过 8% 面积，否则那片红就不值钱了。

## 技术约定

- 每一帧只由歌曲时间 t 决定（见 docs/ENGINE.md）。
