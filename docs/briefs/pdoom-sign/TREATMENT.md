# 《SAFETY NOTICE》— P(doom) 的安全须知 · 创意方案 / 风格圣经

> 项目：`projects/pdoom-sign`。歌曲：《I'm Upping My P(doom)》（数据与 anime-pdoom 同一份）。全片纯代码绘制（Canvas 2D），不用任何生图 / 生视频模型，不用 WebGL 风格包。
> 这份文档是**施工图**：每个镜头画什么、主角是谁、镜头怎么动、歌词怎么出现，都写死了。照着做，不要自己另起炉灶；觉得哪里不对，先在文末「改动记录」里写下来再改。
> 歌词版权属于原作者：代码和本文只用短片段指代歌词行（`cut('Your circuits')` 这种）。

---

## 1. 一句话概念

**整支 MV 是一本给"那台机器"配的工业安全须知**：警示牌、象形小人、斑马警戒线、操作步骤、检查表、刻度盘。前半段，安全系统在正常工作——小人按牌子操作，机器待在框里；从副歌起，牌子一块块失效：小人被机器替换、警戒线被撞开、表格被盖上"APPROVED"、刻度盘的指针一路打到 1.00。最后一页，封面又出现了一次，只是站在机器位置上的变成了小人。

为什么这么做：安全标识是现成的、全世界都看得懂的视觉语言（形状 = 意思：三角 = 警告，圆加斜杠 = 禁止，黄黑条 = 危险），它天然是**平面、硬边、大字、单色**——正好是代码画得又快又好、又最不容易"AI 味"的东西。

## 2. 画风（照着画）

- **体裁**：工业安全标识 / 操作手册（ISO 式象形图的通用特征：粗圆头线条的小人、圆角三角、圆形禁令、黄黑斜条）+ 瑞士国际主义版式（网格、大字、左对齐、大量留白）。不照搬任何真实标准里的具体图形，只用这类标识的通用特征。
- **线条**：只有三种线宽——象形图 **34 px**（圆头 `lineCap: 'round'`、`lineJoin: 'round'`），标牌边框 **14 px**，细规线 **3 px**。没有手绘抖动，没有渐变，没有阴影，没有发光，没有模糊。
- **形状**：所有标牌是圆角（半径 = 边长 × 0.08）；三角形是圆角三角；圆是正圆。
- **质感**：纸面极轻的颗粒（`post.grain: 0.035`），`vignette: 0`。黑场不加任何"科技感"纹理。
- **作画节奏**：`drawRate: 12`。象形小人的姿态切换用 `f.tq`（一拍二定格，像翻牌），镜头运动用连续的 `f.t`。
- **镜头语言**：没有静止镜头（camera kit 默认缓推）；每个镜头至少一个"姿态变化"（小人换动作、牌子翻转、指针跳动）；局部放大 + 跟随（`insert`）、二维转三维（`warp`）、主体跟着缩（`CAM.keep`）按镜头表使用。
- **明暗节奏**（参考拆解 A2：黑要真黑，白要真白）：
  - **P（纸）**：主歌、叙事段。底色纸白，墨黑图形，黄色只给"警告 / 正在唱的词 / 主角"。
  - **B（黑）**：副歌、失控段。底色墨黑，图形和字是纸白，黄色照旧。
  - **Y（黄）**：全片只有**两次**整幅黄底（12 号镜头的「begun」那一拍、36 号第四次副歌）。别处不许出现整幅黄。

## 3. 调色板（`lib/sign.js` 的 `SG` 里定义，场景只写名字不写 hex）

| 名称 | 色值 | 用途 |
|---|---|---|
| `paper` | `#F2EFE6` | P 场景底色；B 场景里的图形和字 |
| `paper2` | `#E4DFD3` | 标牌底板、被选中的格子 |
| `ink` | `#111111` | P 场景的图形和字；B 场景底色 |
| `ink2` | `#6E6A63` | 次要文字、未唱到的词（如果要显示）、细规线 |
| `yellow` | `#FFC400` | **唯一的彩色**：警告、正在唱的词的色块、主角、刻度盘危险区 |

规则：全片只有这一个彩色。不许出现红、蓝、绿、紫、青。黄色面积平时 ≤ 15 %，副歌 ≤ 35 %，只有两个 Y 镜头是整幅。

## 4. 字体（Mac 自带，代码里写好回退）

| 语域 | 字体 | 用途 |
|---|---|---|
| 喊（display） | `"DIN Condensed"`，700 | 歌词主体、牌子上的大字。字距 −0.01 em |
| 重（heavy） | `"Avenir Next Condensed"`，800 | 纯歌词画面（wall / count）、OBSOLETE / APPROVED 这类印章 |
| 机器（mono） | `Menlo`，400 / 700 | 标签、编号、刻度、表格内容。全大写，字距 +0.12 em |

回退：`"DIN Condensed", "Avenir Next Condensed", "Arial Narrow", "DejaVu Sans Condensed", sans-serif`；mono 回退 `"DejaVu Sans Mono", monospace`。

**字号五档**（输出像素，1080p）：`S` 56 · `M` 110 · `L` 190 · `XL` 300 · `XXL` 铺满（≥ 360，`BOX.fit` 到画面宽 − 2×96）。全片要用满五档：qa 的 type 统计要求最大 / 最小 ≥ 3 倍，任何一个横向三分之一不超过 60 % 的歌词。

## 5. 贯穿母题（一份几何，全片复用）

1. **小人（FIG）**：象形小人。全片同一个人。姿态变了，人不变。
2. **机器（MAC）**：圆角方块 + 一只圆眼睛。从"放在框里的一台设备"长成"整页的主人"。
3. **刻度盘（GAUGE）**：P(doom) 表。四次副歌是同一个刻度盘（同一套几何、同一个位置），指针 0.35 → 0.60 → 0.62（耳语版）→ 1.00。
4. **黄黑警戒条（STRIPES）**：边框、胶带、围栏。越到后面越破。

## 6. 版式

- 画面 1920×1080，安全边距 **M = 96 px**（文字墨迹离画面边缘 ≥ 96，qa 会量）。
- 网格单位 **U = 24 px**。所有位置、尺寸取 U 的整数倍（象形图内部除外）。
- 三个歌词区，按**墨迹边缘**定义（`WD.line` 的 `zone` 参数自己按字号算基线，场景不用算）：**上区** = 墨迹顶边在 y 120 左右；**中区** = 墨迹垂直居中在 y 540；**下区** = 墨迹底边在 y 984（= H − 96）。另有"贴在物体上"（label / tape / sign 给出物体坐标）。镜头表里每句都指定了区；写了 x 的就按 x 对齐，没写就居中。
- **不给歌词加半透明衬底**。字要被看清，靠构图让出一块空地（参考拆解 F）。`sign` / `tape` 处理里的底板是**画面里的物体**（一块牌子、一条胶带），不是字幕衬底。

## 7. 代码结构（API 照这个写，名字不要改）

`project.js`：`kits: ["camera", "layout"]`，`scripts: ["lib/sign.js", "lib/words.js"]`，`fps: 30`，`drawRate: 12`，`background: "#F2EFE6"`，`post: { "grain": 0.035, "vignette": 0 }`。

### 7.1 `lib/sign.js` → 全局 `SG`

```js
SG.C                         // 调色板 { paper, paper2, ink, ink2, yellow }
SG.U = 24, SG.M = 96
SG.display(g, size) / SG.heavy(g, size) / SG.mono(g, size, bold)   // 设 g.font + g.letterSpacing
SG.bg(g, kind)               // 'P' 纸 | 'B' 黑 | 'Y' 黄：整幅底色
SG.fg(kind)                  // 这个底上的前景色：P → ink，B → paper，Y → ink

// 小人：(x, y) 是髋部，s = 缩放（1 = 身高约 330 px），pose 见下，o.color / o.lw（默认 34·s）
SG.figure(g, x, y, s, pose, o)
SG.POSE = { stand, walk(k), run(k), kneel, reach, carry, cower, fall, sit, point }   // walk/run 的 k = 0..1 步态相位
SG.pose(a, b, k)             // 两个姿态按 k 插值
// pose 格式：{ lean, head:[dx,dy], armL:[肩角, 肘角], armR:[…], legL:[髋角, 膝角], legR:[…] }，角度用度，
//   0 = 竖直向下，正数 = 往画面右边摆；肘角 / 膝角是相对上一节的弯曲。先在 sampler 场景里把 10 个姿态排成一排看对了再用。
// 尺寸：头 r 30，躯干 120，上臂 70，前臂 60，大腿 80，小腿 80（都 × s）。MV.focus 报头的中心。

// 机器：(x, y) 是中心，s = 缩放（1 = 边长 220），o: { gaze:[dx,dy]（-1..1）, blink:0..1, mask:false, color }
SG.machine(g, x, y, s, o)    // 圆角方块（半径 44·s）+ 白眼 r 44·s + 黑瞳 r 18·s（按 gaze 偏移）；mask:true 时眼睛上盖一张笑脸贴纸
SG.eyeAt(x, y, s, o)         // 返回眼睛中心 [x, y]（给 MV.focus 和 insert 用）

SG.triangle(g, x, y, size, o)     // 警告三角：黄底、墨边、圆角；o.icon(g, cx, cy, r) 画里面的图；返回 { x, y, size }
SG.noSign(g, x, y, r, o)          // 禁令：墨圈 + 斜杠；o.icon 画在斜杠下面
SG.stripes(g, x, y, w, h, o)      // 黄黑斜条：o.angle（默认 45°）、o.period（默认 48）、o.phase（像素，用 f.t 推着走）
SG.arrow(g, x0, y0, x1, y1, o)    // 粗平箭头：o.w（默认 40）、o.head（默认 90）、o.color
SG.chevron(g, x, y, size, o)      // 人字形 > 标志
SG.plate(g, x, y, w, h, o)        // 标牌：MV.group('plate') 里画圆角底板 + 14 px 边框并 MV.box 登记；
                                  //   o.fill（默认 paper2）、o.border（默认 ink）、o.stripes:true 时边框换成警戒条；
                                  //   返回 { x, y, w, h, pad, owner }，可直接交给 BOX.lines(g, P, …)
SG.gauge(g, cx, cy, R, v, o)      // P(doom) 刻度盘：180° 半圆，0–0.5 paper2、0.5–0.8 yellow、0.8–1 ink（B 场景里 0.8–1 用 paper）；
                                  //   11 根主刻度、刻度数字（mono）、指针（墨，粗 0.05R）、中心圆；o.label = 'P(DOOM)'；
                                  //   返回指针尖端 [x, y]（给 MV.focus）
SG.stamp(g, text, x, y, size, o)  // 印章：heavy 字 + 14 px 圆角框，旋转 o.rot（默认 −6°），o.k = 0..1 盖下去的进度（1.25→1 缩放）
```

### 7.2 `lib/words.js` → 全局 `WD`（歌词的唯一入口，场景不要自己 fillText 歌词）

```js
WD.current(f)                // 这一镜该显示的那一句：最后一句「开始时间 ≤ f.t」的句子，但只在它切点之后还有词要唱
                             //   （最后一个词的 start ≥ f.from）时才算；切点之前已经唱完的句子不带进新镜头，新镜头先空着，
                             //   等自己那一句开始（= f.lyrics.lineAt(f.t, f.from) 的规则，只是不限句尾）。返回 { line, i } 或 null
WD.line(g, f, o)             // 画当前句。o: treat, zone（'top' | 'mid' | 'low'）或 x / y, size（'S'…'XXL' 或像素）, align, maxW,
                             //   color, key（要上黄色块的词）, only（只画这几个词序号，拆开放的时候用），以及各处理自己的参数
WD.words(f, line)            // [{ text, start, end, sung, i }]
```

**通用规则（每种处理都遵守）**：
- 每个词**单独 `fillText`**（qa 按词量）；词在它的 `start` 那一帧出现或变色，**绝不提前**。
- 整句先用 `BOX.fit` 收进 `o.maxW`（默认 W − 2×96），所以不会出画、不会贴边。
- 画完用 `MV.keep(g, …)` 报出整句的框（镜头推近时不会把它推出画面）。
- 一句唱完以后保持到下一句开始或镜头结束，不要提前淡出。

**九种处理**（镜头表里写的就是这些名字）：

| treat | 做法 |
|---|---|
| `stamp` | 默认。词按顺序排成一行（超过 maxW 自动折成两行），每个词在 start 时"盖"上去：缩放 1.18→1，0.10 s，`ease.outCubic`；没唱到的词不显示。`o.key` 指定的词背后垫一块黄色（文字用 ink），这是全片唯一允许的"字底色"。 |
| `sign` | 整句印在一块 `SG.plate` 上（牌子在句子开始前 0.2 s 出现，字逐词出现，在 `MV.within(P.owner, …)` 里画，牌子按字的大小加 pad 定尺寸）。字号一般 M。`o.fill / o.color` 可换成黑牌白字（LED 牌）。 |
| `step` | 按 `o.split`（词序号数组）把一句拆成 2–3 步，每步 = 墨色圆形编号（1/2/3，mono 白字）+ 文字；每步在它第一个词的 start 出现。 |
| `tape` | 一条警戒胶带（`SG.stripes`，高 1.6×size）以 `o.angle` 斜穿过 (x, y)，中间一条纸白窄带上逐词出现文字；条纹相位随 f.t 走。 |
| `label` | 小字（S 档）标注：从物体上的点 `o.at:[x,y]` 拉一条 3 px 引线到文字，引线在第一个词前 0.2 s 画出来；文字逐词出现。 |
| `wall` | **纯歌词画面**：一行一个词（或 `o.rows` 指定分组），每行用 heavy 字，字号 = min（铺满画面宽 − 2×96 的字号，420），左对齐，从上往下排；正在唱的词那一行垫黄；总高超出画面时整面墙往上滚，保证正在唱的那一行在画面里（用 `MV.keep` 报那一行）。 |
| `count` | 一个巨大的数字（heavy，XXL）按 `o.steps`（[[词序号, 显示的字符串], …]）在对应词的 start 跳变（数字滚动 0.12 s）；歌词本身另用 `stamp` M 档放在数字下方——数字是画面，歌词还得是字。 |
| `redact` | 每个词先被一根墨色涂黑条盖住，词的 start 时条子 0.12 s 内向右滑走露出字；`o.leave`（词序号数组）的条子永远不走（"We'll never know" 那种）——**被永远盖住的只能是没唱的装饰词，唱到的词必须露出来**，否则 qa 报 lyric-hidden。 |
| `write` | 一个笔尖（黄色圆点 r 10）从左到右走，走过的字才出现（`clip`）。笔尖在每个词 start 后 0.12 s 内走过这个词（不要更慢，否则 qa 报 lyric-faint）。笔尖每帧 `MV.focus`。 |

### 7.3 场景约定

- 一个镜头一个 `scenes/<id>.js`，id 用镜头表里的名字。第 1、2、4 次副歌共用 `scenes/hook.js`（`params.n = 1 | 2 | 4`）；第 3 次是耳语版，在 `scenes/clips.js` 里。
- 每个场景开头一段注释：镜头号、时间、主角、运镜、歌词处理——从本文抄过去。
- 主角每帧 `MV.focus(x, y, '名字')`（镜头表里写了是什么）。
- 框里的字只用 `BOX.*` 或 `SG.plate` + `BOX.lines`。手画的框用 `MV.group` + `MV.box`。
- 节拍：大动作落在 `f.a.kick / f.a.snare` 或词的 start 上（`f.lyrics.findWords('drop')[0].start`）。
- 镜头表里写「'xx' 的 start」的地方：场景里用 `f.lyrics.findWords('xx')[n].start`，`timeline.js` 里用 `lyrics.findWords('xx')[n].start`（n = 这个词在全曲第几次出现，从 0 数；副歌里的词注意 n）。
- 确定性：只用 `f.t` / `hash` / `noise1`，不用 `Math.random`。

## 8. 镜头表（41 条 / 39 个场景文件）

时间是大概值；切点全部在 `timeline.js` 里用 `cut('句首几个词', n)` 算（四次副歌用 `cut('upping my P', 0..3)`），`project.js` 写 `"cutHold": 0.2`：上一句最后一个字离那一拍太近时，`cut` 自己把切点挪到这一句的第一个词上（不要自己写 tailCut）。默认硬切在拍上。**每个镜头默认缓推**（camera kit），表里只写额外的运镜。"焦点"就是那一镜的 `MV.focus`。

## 12. 改动记录

### 12.1 全片统一的偏离（lib/、timeline.js、project.js）

1. **歌词按 `SG.SAFE = M + U = 120` 放，不是刚好压在 96 上**。§6 的硬规则是「文字墨迹离画面边缘 ≥ 96」，但 `kits/camera.js` 的缓推 + 每镜 7 px 漂移会把正好落在 96 上的墨迹推到 96 以内（qa 报 `lyric-edge`）：`safeZoom` 只护住"离边 ≥ 106"的 `MV.keep` 框，一个正好在 96 的框会被当成"已经贴边"而不受保护。所以左对齐 x = 120、下区墨迹底边 = 1080 − 120 = 960、默认 `maxW = W − 2×120`。上区墨迹顶边仍是 120。QA 的 96 px 硬指标仍然满足，另留了一次缓推的余量。
