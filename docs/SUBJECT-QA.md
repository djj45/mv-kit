# 歌词与主体遮挡检查

`lyric-cover` 判断歌词覆盖了多少画面细节，不能可靠识别暗色瞳孔或低细节人脸。新增的主体保护区由镜头声明“这里不能被歌词遮挡”，复用现有 `render.py … qa`、时间定位、JSON/Markdown 报告和截图，不改变绘制、运镜或编码。

## 标注关键区域

在主体可见的每一帧，用绘制它的同一个 Canvas 上下文声明紧贴关键部位的矩形：

```js
// 放在场景 render(g, f) 内；坐标随主体运动更新。
MV.protect(g, eyeX - 100, eyeY - 70, 200, 140, {
  name: 'pupil',
  severity: 'warn',  // 默认；明确禁止遮挡时用 'error'
  maxOverlap: 0.01   // 默认：允许覆盖可见保护区面积的 1%
});
```

区域跟随 `g` 的平移、旋转、缩放和后期相机的二维变换；在 `MV.overlay` 内声明的区域直接使用屏幕坐标。`MV.protect` 不画东西、不改变相机的 `MV.keep` 限制，正常导出时为空操作。名称应在镜头内稳定且能区分不同主体。

只标注当前可见的重要部位，不要把整个背景或故意被前景遮挡的外轮廓都框进去。主体暂时消失时不要声明。范围、容差或严重程度无效会报告场景错误。参考 VITRAIL 的 `maw`：机器面部在其局部变换内声明，眼睛张开后声明瞳孔中心。

## 检测与报告

```sh
uv run tools/render.py projects/my-song qa
uv run tools/render.py projects/my-song qa --from 12 --to 24
```

- `subject-overlap`：歌词墨迹外接四边形，或歌词／屏幕叠加层实际改变的像素，与保护区重叠。**不依赖背景亮度或边缘密度**。默认警告；区域声明 `severity: 'error'` 时产生错误并使 QA 返回 1。
- `subject-unverified`：转场合成、三维 warp 等非仿射变形、离屏 Canvas 标注、过小／画外区域或透明声明无法准确验证，报告警告，不记作无遮挡通过。转场仍取样，但不会用错误的坐标给出通过结论。
- 截图红框表示检测到的遮挡，黄框表示保护区；报告包含镜头、时间、面积占比、阈值。重复发现按区域聚合，并保留最严重的样本。

在原有采样之外，补查逐词开始、`reads`／`sync` 事件、insert 开始与完成、镜头与淡入边界的相邻帧。采样不是逐帧穷尽，快速运动仍需动态审看；非常短的遮挡可能漏检。

`qa.json` 的 `subjectProtection` 单独记录覆盖情况：`unverified`（没有可测区域）、`partial`（部分镜头未标注或部分样本不能测）、`sampled`（本次范围的镜头已声明且区域样本可测）、`disabled`（相关检查被关闭）。`sampled` 不是无问题结论，需要同时读 findings。没有声明的镜头列在 `unmarkedShots`，不能因总错误数为 0 就声称全片主体没有被遮挡。

检测按四分之一设计分辨率采样，忽略不足两个采样像素的遮挡；文字使用墨迹边界，是保守估计，字间空隙、描边和局部裁剪可能需要人工复核。歌词板应画在 `MV.overlay`，或用 `MV.lyric` 包住板与歌词一起绘制；没有归属声明的普通场景图形不被当作歌词板。屏幕层包含其他装饰时，它们也可能触发区域保护提示。不要为了躲检查给歌词加 `MV.decor`。

此功能检查烧录歌词与工程内的叠加层。外置 SRT/VTT 的位置由播放器决定，只能按明确约定的播放样式另行审看。也不要求所有风格都使用顶部字幕或前景石梁。

## 回归与现有交付

```sh
uv run python -B -m unittest discover -s tests -p test_subjectqa.py -v
uv run python tests/subject_browser.py --out artifacts/subject
# 本机存在 VITRAIL 时，额外检查实际镜头和整片，产物独立保存：
uv run python tests/subject_browser.py --out artifacts/subject-vitrail --vitrail
```

浏览器回归涵盖暗色／低对比主体、透明文字、字幕底板、安全位置、场景局部变换、最大推进、屏幕坐标、转场与三维变形未验证、错误级别及标注截图。VITRAIL 正反例在浏览器内把歌词临时放回画面中心，验证告警后恢复；不修改实际镜头布局。CI 使用合成素材，不依赖 VITRAIL、歌曲或歌词。

QA 标注不改变导出像素，但引擎源码和场景源码属于现有成片回执的依赖。升级后的旧回执可能被判为过期，这是正常的完整性保护；下一次交付需重新导出并生成匹配的回执／审片页／包，不要手工重写旧回执来绕过检查。本轮功能验证不自动重导出或替换已交付的成片。
